## Phase 7 — 端到端主链路

### 链路 A：新学员完整生命周期

```
PAR: parent1 为"张新宇"(EDU-09) 在线报名"少儿美术启蒙班"(course=1)
→ enrollment status=1 待审核
EDU: edu 审核 → 通过, status=2, 24h留位
FIN: finance 缴费 ¥2400/24课时
→ enrollment status=3, payment_record + lesson_account(24/24)
→ 张新宇加入美术A班 class_student(class_id=1)
→ 满额检查(CAP=15, 当前1人)需通过
TCH: teacher1 第一节课考勤 → 扣1课时, 余额23 + learning_record
PAR: parent1 查看 → 课表 + 学情 + 余额23
FIN: finance 核算 teacher1 7月薪资 → 主讲课时+1
```

### 链路 B：退费完整链路

```
PAR: parent6(21) 对吴俊杰(6)钢琴考级 → 查看已提交的退费 id=4
FIN: finance(3) 审核 id=4 → 通过
→ CAS: status 1→2
→ 计算: ¥4800/16课时=¥300/课时
→ 退款 ¥300, 扣1课时, 余额 13.5
→ 流水: sourceType=4, changeType=2(负向)
→ 如全额: enrollment.status=6, class_student.status=3
PAR: parent6 查看 → 余额更新
```

### 链路 C：薪资全周期

```
FIN: 设置张老师(4)薪资规则 → 美术¥80, 水彩¥70, 素描¥100
TCH: teacher1 6-7月授课 → 23节(含 seed 课次)
FIN: 核算 7月 → 统计 status=2 且有考勤(status∈1,2) 的课次
     主讲: Σ(mainLessons × unitPrice)
     代课: Σ(subLessons × unitPrice × substituteRate)
     total = base + substitute + bonus
→ status=1 待确认
FIN: 确认 → CAS 1→2
ADM: 运营看板 → 教师工作量统计
```
