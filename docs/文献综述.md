# 文献综述

> 课题：艺体培训机构全流程教务管理平台的设计与实现
> 范围：国内外近三年（2024—2026 为主）相关研究
> 说明：所引文献均为真实可检索文献，全文存于 `docs/refs/`。

---

## 一、引言

艺体培训（含音乐、舞蹈、美术、体育等）是素质教育的重要组成部分，其课程类型多、排课频次高、教师多为兼职、学员以未成年人为主、收入依赖课时包销售，使教务管理成为信息密度最高、最易出错的环节。以电子表格与纸质登记为主的管理方式，在数据一致性、排课冲突、课时核算与决策支撑等方面暴露出明显局限。本文围绕智能排课与冲突检测、教务管理与业务流程信息化、课时与薪资自动核算、学情分析与流失预警、数据可视化与移动端五个方向，对近三年的国内外研究进行梳理与评述，并指出本课题的切入点。

## 二、智能排课与冲突检测

排课本质上是受多重约束的组合优化问题，冲突检测则是排课系统正确性的基础。

在工程实现层面，黄玉蕾等[1]针对学生规模扩大后学习需求与教室、教师资源之间的冲突，完成了排课系统的需求分析、逻辑结构设计与信息表设计，采用 B/S 架构与关系型数据库支撑教务人员、教师与学生的课程排列与查询。该研究为排课系统的数据建模提供了完整范式，但对排课算法本身着墨有限。

在冲突检测方面，朱小影等[8]将日程冲突检测抽象为**时间区间的重叠检测**，基于区间树实现高效的插入、删除与查询，并借助 Isabelle 定理证明器完成算法的形式化建模与自动化验证。其"时间区间重叠"的抽象，与本课题冲突检测的核心判断（两时间段有交叠当且仅当 `start1<end2` 且 `end1>start2`）原理一致。

在算法优化方面，Han 等[9]提出遗传算法与动态规划相结合的混合方法，以带判定机制的交换操作与强制修复变异避免陷入局部最优，并采用贪心策略完成教室分配，实验显示排课质量较传统遗传算法提升约 46.99%；Xiang 等[10]设计两阶段元启发式算法，先以图着色对课程聚类、再以增强禁忌搜索分配时间段，在真实数据上验证了效率与合理性。

述评：相关研究呈"数据建模—算法优化—正确性验证"的分化趋势，但多以高校全校为对象，缺少面向中小型艺体培训机构、能在教师/教室/教室预约/班级/跨班学员多个维度做时间交叉检测，并配合可视化拖拽调课的轻量级实现。

## 三、教务管理与业务流程信息化

杨茜等[6]针对传统教务管理数据割裂、效率低下的问题，设计并实现了基于 B/S 架构的高校教务管理系统，采用 Vue 3、ASP.NET Core 与 MySQL，构建学生、教师、管理员三大角色子平台，涵盖选课、成绩、教学档案等十余项功能，并以 RBAC + Claim 实现细粒度权限控制；系统试运行中教师成绩录入耗时降低 42%、选课差错率由 2.1% 降至 0.3%。张浩[7]采用系统分析与模块化设计方法构建档案管理数字化系统，实现了档案信息的快速检索。黄玉蕾等[1]的排课系统则在业务层面与教务系统相互衔接。

述评：高校教务管理系统的研究已较成熟，但业务重心多在选课、成绩与档案，缺少面向艺体培训机构、以"招生—排课—考勤—课时—财务—学情"为主线的业务闭环设计，机构特有的收费与课时包模式鲜有体现。

## 四、课时与薪资自动核算

薪资核算方面，肖青云等[4]针对新职工工资人工核算劳动重复、过程低效的问题，设计并实现了基于 XML 的轻量级工资核算系统，可依据岗聘表与档案信息自动完成**工资套算、基数确定、扣除计算与补发合计**四项任务，并支持文档保存与历史查询，已在实际业务中稳定运行，验证了以规则映射实现薪资自动核算的可行性。

并发一致性方面，Pophali[11]系统比较了数据库四种隔离级别以及乐观锁与悲观锁在高并发扣减场景下的表现，指出乐观锁通过版本校验在提交时检测冲突，可在冲突概率较低时避免超扣并提升吞吐。该问题与本课题课时账户所采用的"版本号乐观锁 / `FOR UPDATE`"在性质上同构。

述评：薪资核算与并发控制各自已有较成熟的研究，但二者在既有文献中相对独立；将考勤状态机、课时余额扣减与流水写入纳入同一事务、并以乐观锁防止并发覆盖的"课时自动扣减"，在中小型培训机构场景下仍缺少针对性研究。此外，退费金额的上限校验以业务规则为主，现有文献多从法律与监管视角讨论预付费治理，缺少算法层面的论述。

## 五、学情分析与流失预警

庄俊玺等[3]针对现有成绩预测方法对日常行为数据关注不足、特征单一等问题，提出基于三元深度融合的行为驱动成绩预警模型，从群体与个体行为出发提取规律性、活跃性与勤奋性特征并加以融合，提升了预警的准确性与前置性。该研究以行为数据刻画学业风险，与本课题以"到课沉寂度、缺勤倾向"刻画流失风险的思路一致。

在流失预测方向，Huynh-Cam 等[12]利用入学前即可获得的人口学、家庭背景与财务状况信息构建早期预测模型并提取关键影响因子；Gutierrez-Pachas 等[13]综合学术、社会经济与公平三类因素，结合机器学习与生存分析支持辍学决策，说明流失风险可由多源因素共同刻画。

述评：现有研究以机器学习模型为主、预测精度较高，但对数据规模与算力有一定要求，且模型的可解释性有限。对中小型艺体培训机构而言，以可解释的多因子规则构建预警，更契合其数据规模小、重视干预可追溯的需求，而这一形态在既有研究中较为少见。

## 六、数据可视化与移动端应用

可视化方面，刘梦等[2]围绕"数据已成为企业核心资产"的背景，将 ECharts 可视化技术应用于数据管理平台，通过丰富的图表组件实现多维数据的直观呈现，为管理决策提供辅助，与本课题以 ECharts 构建运营看板的路径一致。移动端方面，韦彩仁等[5]针对传统学生信息管理系统实时性与便携性受限的问题，基于 Uni-App（Vue.js 开发界面、SpringBoot 开发后端）实现信息管理系统学生端，一次开发即可适配微信、支付宝等多端小程序，验证了跨端框架在移动端教育信息管理中的适用性。

述评：数据可视化与移动端技术方案均已相对成熟，但既有研究多聚焦单一端，缺少将可视化看板与移动端同教务管理平台深度集成、共享同一数据模型与业务规则的整体设计。

## 七、研究述评与本课题切入点

综合来看，上述各方向成果丰富，但整体呈"点状分布、以高校为对象"的特点：或聚焦单一算法（排课优化、冲突检测），或聚焦单一环节（工资核算、档案管理），或聚焦单一终端，难以直接拼装为面向中小型艺体培训机构的可用、可维护的整体系统。其主要不足在于：一是缺少覆盖"招生—排课—考勤—课时—财务—学情"全业务链条的工程化落地系统；二是各环节缺少以统一数据模型串联并形成业务闭环的设计；三是在并发一致性、权限隔离与可维护性等工程质量属性上保障不足；四是以可解释规则构建的流失预警、以及课时扣减与薪资核算的一体化实现仍属空白。

本课题以上述不足为出发点，以一个完整、可上线的工程系统为目标：在算法层面，以时间区间重叠检测为基础实现教师、教室、教室预约、班级、跨班学员五维排课冲突检测，以约束满足与贪心策略实现批量排课；在核算层面，以考勤状态机驱动课时自动扣减、以乐观锁保障并发安全，以规则映射实现教师薪资自动核算并支持确认后调整留痕；在决策与呈现层面，以可解释因子构建流失预警，以 ECharts 构建运营看板、以跨端框架支撑家长与教师移动端，使艺体培训机构的教务管理实现数字化、自动化与可决策化。
