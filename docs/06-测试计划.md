# 测试计划

> **版本状态**：v0.8 规划版，基于 `03-软件需求规格说明书.md` 编制。本文档为测试计划，待系统开发完成并执行测试后，应补充真实结果形成测试报告。

## 1. 测试目标与范围

### 1.1 测试目标

验证“艺术培训机构全流程教务管理平台”是否满足需求规格说明书中的功能性和非功能性需求，重点验证：

1. 五类角色登录、菜单权限和接口权限正确；
2. 报名缴费、排课、考勤、课时扣减、学情记录核心教务流程正确；
3. 收费、续费、退费和教师薪资结算数据准确可追溯；
4. 排课冲突检测、课时不足校验、薪资计算等核心规则正确；
5. 招生、到课率、课时消耗、营收、教师工作量等统计结果正确；
6. 系统具备基本安全防护和异常处理能力。

### 1.2 测试范围

覆盖 `03-软件需求规格说明书.md` 第4节全部功能需求（FR-P-*、FR-T-*、FR-E-*、FR-F-*、FR-A-*、FR-S-*）以及第5节非功能性需求。

## 2. 测试策略

| 测试类型 | 说明 | 工具/方法建议 |
|---|---|---|
| 单元测试 | 针对排课冲突、课时扣减、退费计算、薪资核算等核心规则编写测试 | JUnit + Mockito |
| 接口测试 | 验证 REST API 请求参数、响应字段、异常分支和权限控制 | Apifox / Postman / JMeter |
| 集成测试 | 按角色执行报名、排课、考勤、收费、薪资、统计等跨模块流程 | 手工测试 + 自动化脚本可选 |
| 移动端与管理后台测试 | 验证 uni-app 移动端页面、管理后台页面、表单校验、权限菜单、图表展示和报表导出 | 微信开发者工具/H5 浏览器/PC 浏览器手工测试 |
| 性能测试 | 测试课表查询、统计看板、批量排课等高频或复杂接口表现 | JMeter |
| 安全测试 | 验证登录鉴权、越权访问、SQL 注入、XSS 和敏感操作日志 | 人工检查 + 工具辅助 |

## 6. 安全测试与审计

### 6.1 计划开展的安全测试项

| 测试项 | 测试方法 |
|---|---|
| SQL 注入测试 | 对搜索、筛选、登录等接口输入特殊字符和注入语句 |
| XSS 测试 | 在公告、作业、教师评语等文本中注入脚本标签 |
| 越权访问测试 | 使用低权限角色调用高权限接口，验证是否拒绝 |
| 资源归属测试 | 家长尝试查看非绑定学员信息，教师尝试操作非本人课次 |
| 鉴权失效测试 | 使用过期或篡改 Token 访问接口 |
| 密码安全测试 | 检查数据库密码是否为哈希值 |
| 敏感操作日志测试 | 执行收费、退费、薪资、权限变更后检查 operation_log |

## 7. 缺陷管理流程

1. 发现缺陷后登记缺陷编号、所属模块、复现步骤、期望结果、实际结果和严重程度；
2. 严重程度分为致命、严重、一般、建议；
3. 修复后执行回归测试；
4. 未能在测试周期内修复的问题需在测试报告中标注为已知问题。

## 8. 验收标准

- 五类角色核心功能均可正常使用；
- 报名、排课、考勤、扣课时、收费、薪资、统计主流程全部通过；
- 排课冲突、课时不足、越权访问等异常流程能够正确拦截；
- 统计数据与业务明细数据口径一致；
- 无高风险且未整改的安全问题；
- 系统可在演示环境稳定运行，并具备数据库脚本、测试报告和用户操作手册。
