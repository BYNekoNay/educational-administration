# 项目脚手架与环境规范

> **版本状态**：v0.8 规划版。本文档约定项目目录、依赖版本、包名和配置骨架。

## 1. 推荐环境版本

| 项目 | 版本建议 |
|---|---|
| JDK | 17 |
| Spring Boot | 3.x 或按实际依赖锁定 |
| Maven | 3.8+ |
| MySQL | 8.0 |
| Redis | 6.x+ |
| Node.js | 18 LTS |
| Vue | 3.x |
| uni-app | 当前稳定版本 |
| Element Plus | 2.x |
| ECharts | 5.x |
| HBuilderX / 微信开发者工具 | 最新稳定版 |

## 2. 仓库目录建议

```
educational-administration/
├── backend/                 # Spring Boot 后端
├── mobile-uniapp/           # 家长端、教师端 uni-app
├── admin-web/               # 教务/财务/管理员 Vue3 后台
├── docs/                    # 毕业设计文档
├── sql/                     # 数据库脚本，可与后端 resources/sql 同步
├── README.md
└── 项目.md
```

## 3. 后端包名

建议根包名：`com.pzhu.eduadmin`。

## 4. 后端配置骨架

```yaml
server:
  port: 8080

spring:
  datasource:
    url: jdbc:mysql://localhost:3306/edu_admin?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai
    username: root
    password: root
  data:
    redis:
      host: localhost
      port: 6379

jwt:
  secret: change-me
  expire-minutes: 120

file:
  upload-dir: ./uploads
```

## 5. mobile-uniapp 配置建议

- 使用 HBuilderX 或 CLI 模式创建项目；
- `manifest.json` 配置应用名称、AppID 和平台能力；
- `pages.json` 维护家长端、教师端页面路由；
- `uni.scss` 或全局样式文件统一主题色与间距；
- 测试阶段优先运行 H5，演示阶段可运行微信小程序版本。

接口基地址可通过环境文件或 `config.js` 维护，例如：

```js
export const BASE_URL = 'http://localhost:8080/api'
```

## 6. admin-web 配置骨架

`.env.development`：

```env
VITE_API_BASE_URL=/api
```

Vite 代理：

```js
server: {
  proxy: {
    '/api': {
      target: 'http://localhost:8080',
      changeOrigin: true
    }
  }
}
```

## 7. 初始化账号建议

| 角色 | 用户名 | 用途 |
|---|---|---|
| 超级管理员 | admin | 权限、配置、全局看板 |
| 教务管理员 | edu | 课程、班级、排课、学员 |
| 财务管理员 | finance | 收费、退费、薪资 |
| 授课教师 | teacher | 课表、考勤、学情 |
| 学员家长 | parent | 报名、课表、课时、学情 |

## 8. 初始化数据建议

- 4 类课程：美术、钢琴、舞蹈、书法；
- 3-5 名教师；
- 3 个教室；
- 10 名学员和对应家长；
- 若干班级、课次、考勤、收费和薪资规则；
- 至少一组排课冲突演示数据。

## 9. 开发命令建议

后端：

```bash
mvn spring-boot:run
```

管理后台：

```bash
cd admin-web
npm install
npm run dev
```

uni-app：

- 使用 HBuilderX 运行到浏览器或微信开发者工具；
- 如使用 CLI，可根据项目脚手架运行 H5 或小程序构建命令。

打包：

```bash
cd admin-web
npm run build
cd ..
mvn clean package
```
