# 毕业答辩 PPT

- `艺培通毕业答辩.pptx` —— 22 页终稿，页序与 `答辩讲稿.md` 的 15 分钟口播版（第 1~22 页）严格对齐。
- `build_defence_deck.js` —— 生成脚本；`assets/` —— 内嵌素材（7 张图）。

## 重新生成

脚本依赖 `pptxgenjs@4.0.1`，需先安装依赖（不把 `node_modules` 入库）：

```bash
cd docs/defence/ppt
npm install          # 仅首次；安装 pptxgenjs
node build_defence_deck.js "../艺培通毕业答辩.pptx"
```

不传参数时默认输出到当前目录的 `艺培通毕业答辩.pptx`。

| 4 | 国内外研究与缺口 | 同上 |

| 7-9 | 总体架构、技术选型、数据模型 | 系统架构与技术选型 |

| 17-19 | 成果总览、测试体系、最有价值的一次缺陷 | 实现成果与测试验证 |

## 说明

- 主题色、字体与防溢出容器系统沿用开题答辩版脚本，视觉成套。
- 图 13/14/15 分别用薪资、流失预警、运营看板截图；若答辩前重新截取了界面，
  替换 `assets/` 下同名文件后重新执行脚本即可（文件名中的尺寸需与实际一致，
  容器系统依赖该尺寸做等比缩放）。
