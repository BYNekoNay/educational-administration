## 🔴 一、UML 关系方向（第二轮实测：4 对 2 错）

UML 规定：`基用例 --«include»--> 被包含用例`、`扩展用例 --«extend»--> 被扩展用例`，**箭头都指向右边那个节点**。
下表为**放大原图逐条核对**的结果（非目测推断）：

| 图中现状（读作 A → B） | 语义 | 判定 | 改法 |
|---|---|---|---|
| 在线报名 → 缴费与续费（include） | 报名包含缴费 | ✅ 正确 | 不动 |
| 课堂考勤 → 课时自动扣减（include） | 考勤包含扣课时 | ✅ 正确 | 不动 |
| 智能排课 → 排课冲突检测（include） | 排课包含冲突检测 | ✅ 正确 | 不动 |
| 退费审核 → 退费课时回冲（include） | 审核包含回冲 | ✅ 正确（已修正） | 不动 |
| **营收与课时统计 → 报表导出（extend）** | 「统计扩展导出」 | ❌ **反了** | 改为 **报表导出 → 营收与课时统计** |
| **学员管理与报名审核 → 转班退班（extend）** | 「学员管理扩展转班退班」 | ❌ **反了** | 改为 **转班退班 → 学员管理与报名审核** |

> 记忆要点：**「扩展」箭头从"可选的那个功能"指向"基础功能"**。
> 转班退班是"学员管理"的可选扩展 → 转班退班指向学员管理；
> 报表导出是"营收统计"的可选扩展 → 报表导出指向营收与课时统计。

## 🔴 二、用例清单与第 9/10 页的「21 项功能」对不上

第 9/10 页统一口径的 21 项功能如下，逐项比对当前用例图：

| 角色 | 第 9/10 页的 21 项 | 用例图里 | 差异 |
|---|---|---|---|
| 学员家长 | 在线报名缴费 / 课表学情查看 / 课时余额流水 / **到期消息提醒** | 在线报名、查看课表与学情、查询课时余额 | **缺「到期消息提醒」** |
| 授课教师 | 授课课表提醒 / **调课申请** / 四态课堂考勤 / **学情课时统计** | 查看授课课表、课堂考勤、作业发布与学情点评、请假审批 | **缺「调课申请」「学情课时统计」；多了「作业发布与学情点评」「请假审批」** |
| 教务管理员 | 课程班级管理 / 智能排课调课 / 报名审核分班 / **教室资源管理** / 考级管理 | 课程班级管理、智能排课、调课审批、学员管理与报名审核、考级管理 | **缺「教室资源管理」；「调课审批」是新增** |
| 财务管理员 | 收费与续费 / 退费审核 / 薪资自动结算 / 营收统计报表 | 收费与续费登记、退费审核、教师薪资结算、营收与课时统计 | 4 项对应，仅用词不同 |
| 超级管理员 | 人员权限管理 / 机构配置 / **公告管理** / 全局运营看板 | 用户与角色权限管理、机构配置与公告管理(合并)、全局运营看板 | **「机构配置+公告管理」被合并成 1 个，少 1 项** |

**建议**：把用例图的 **21 个主用例与第 9/10 页逐字对齐**（含「到期消息提醒」「调课申请」「学情课时统计」「教室资源管理」），机构配置与公告管理拆成两个；再在其上叠加 4 个 include/extend 子用例（缴费与续费、课时自动扣减、排课冲突检测、退费课时回冲）与 1 个公共用例（登录与身份认证）。

> 评委手里如果有开题报告，「用例图」和「功能结构图」两页的口径不一致会被直接问。

## 🟠 三、版面问题

1. **「登录与身份认证」连线过多、走线过长**（放大实测确认）
   该用例位于图中央偏上，**有 3 条箭头分别从上方、下方、右方汇入**，其中上、下两条是沿系统边界框走的**超长竖线，几乎贯穿整张图**；这些线与边界框平行且贴近，视觉上形成"双边框"。
   → 建议三选一：(a) 移到边界框**左上角**；(b) 干脆**删掉**（登录属技术用例，不是业务用例）；(c) 恢复「用户」基类参与者 + 5 条泛化箭头，由基类统一连登录。

2. **左密右疏**：左侧三个角色（家长/教师/教务）连线密集，中间偏右出现大片空白，右侧两个角色（超管/财务）稀疏。建议把右侧用例整体左移、或把财务的 4 个用例上提与教师对齐。

3. **椭圆规格不一**：长文本（如「学员管理与报名审核」「作业发布与学情点评」）被拉成长椭圆，短文本是圆椭圆，大小参差。建议**统一椭圆宽度**，长文本换行显示。

4. **关联线不要贴边界框走**：目前多条关联线沿着矩形框的左/下/右边走行，与边框重合。

## 🟡 五、导出规格（投影可读性硬指标）

| 项 | 现状 | 要求 |
|---|---|---|
| 分辨率 | 约 947 × 706 px，铺满 6.97 英寸 ≈ **136 DPI** | 导出 **≥ 1900 px 宽**（2 倍图），否则投影放大后字发虚 |
| 比例 | 4:3 偏方 | 与幻灯片内容区一致（约 7:6），避免拉伸变形 |

| 连线 | 有折线绕行 | 全部走直线，禁止绕到系统边界框以外 |
| 编辑态痕迹 | 截图中「在线报名」等椭圆上可见**蓝色圆形锚点**（选中/连接点） | 导出 PNG 前点空白处取消选中，确认产物里没有蓝色锚点 |
