# 数据库规范

> **版本状态**：v1.0 正式版，已与实际代码和测试结果核对，验收日期 2026-07-19。

## 1. 通用规范

- 数据库：MySQL 8.0；
- 字符集：utf8mb4；
- 存储引擎：InnoDB；
- 表名、字段名：小写下划线；
- 主键：`bigint` 自增；
- 通用字段：`id`、`create_time`、`update_time`、`is_deleted`；
- 金额字段：`decimal(10,2)`；
- 课时字段：`decimal(6,2)`；
- 状态字段：`tinyint`，枚举含义在字段注释或字典表中维护。

CREATE TABLE schedule_lock (
  id TINYINT PRIMARY KEY,
  lock_name VARCHAR(50) NOT NULL UNIQUE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
INSERT INTO schedule_lock (id, lock_name) VALUES (1, 'auto_schedule');
```

> `status` 枚举：1-待上课，2-已完成，3-已取消，4-已调课；`attendance.status` 枚举：1-到课，2-迟到，3-请假，4-缺勤。冲突检测查询须加 `status IN (1,2)` 过滤，排除已取消/已调课的旧课次（详见 `05` §5.1、`12` §2.3）。学员维度冲突检测通过 `schedule_lesson JOIN class_student ON schedule_lesson.class_id = class_student.class_id` 按 `student_id` 分组后复用同一时间交叉公式。智能排课事务先以 `SELECT ... FOR UPDATE` 锁定 `schedule_lock` 固定行，防止多实例并发请求在未提交窗口内生成重复课次。

```sql

### 3.5 课时账户与流水

```sql
CREATE TABLE lesson_account (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  student_id BIGINT NOT NULL,
  course_id BIGINT NOT NULL,
  total_lessons DECIMAL(6,2) NOT NULL DEFAULT 0,
  remaining_lessons DECIMAL(6,2) NOT NULL DEFAULT 0 CHECK (remaining_lessons >= 0),
  expire_date DATE,
  version INT NOT NULL DEFAULT 0,
  create_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  update_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  is_deleted TINYINT NOT NULL DEFAULT 0,
  UNIQUE KEY uk_student_course (student_id, course_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

> **并发扣减说明**：`remaining_lessons` 更新必须通过乐观锁完成，即 `UPDATE lesson_account SET remaining_lessons = ?, version = version + 1 WHERE id = ? AND version = ?`，更新影响行数为 0 时应重新查询余额并重试或提示"课时账户已被其他操作修改，请重试"，防止同一学员在不同课次几乎同时提交考勤时并发扣减导致余额被扣成负数（丢失更新）。`CHECK (remaining_lessons >= 0)` 作为数据库层兜底约束。

CREATE TABLE lesson_flow (

  remark VARCHAR(255),

### 3.7 权限与薪资调整

```sql
CREATE TABLE role (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  role_code VARCHAR(30) NOT NULL UNIQUE,
  role_name VARCHAR(50) NOT NULL,
  create_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  update_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  is_deleted TINYINT NOT NULL DEFAULT 0
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

CREATE TABLE permission (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  permission_code VARCHAR(60) NOT NULL UNIQUE,
  path VARCHAR(100),
  type TINYINT NOT NULL COMMENT '1-菜单，2-接口',
  create_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  update_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  is_deleted TINYINT NOT NULL DEFAULT 0
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

CREATE TABLE role_permission (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  role_code VARCHAR(30) NOT NULL,
  permission_code VARCHAR(60) NOT NULL,
  create_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  update_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  is_deleted TINYINT NOT NULL DEFAULT 0,
  -- 唯一键不包含 is_deleted：业务上"删除-重建"权限时使用真删（mapper.realDeleteByRoleCode），
  -- 而非依赖 @TableLogic 标记 is_deleted=1，否则逻辑删除行会持续占用唯一键导致重建失败。
  UNIQUE KEY uk_role_permission (role_code, permission_code)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

CREATE TABLE salary_adjustment (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  teacher_salary_id BIGINT NOT NULL,
  adjust_amount DECIMAL(10,2) NOT NULL COMMENT '正数为补发，负数为扣回',
  reason VARCHAR(255) NOT NULL,
  operator_id BIGINT NOT NULL,
  create_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  is_deleted TINYINT NOT NULL DEFAULT 0,
  INDEX idx_teacher_salary_id (teacher_salary_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

> `user.role_code` 建议在应用层校验其值必须存在于 `role.role_code`（MySQL 8.0 外键在高并发写入下有额外开销，是否建物理外键由开发者按性能需要取舍，但至少应用层需保证引用完整性）。`role_permission` 支撑 `RoleController`/`PermissionService` 的角色权限配置能力（对应 `11` §2）。

## 4. 索引设计

| 表 | 索引 | 目的 |
|---|---|---|
| schedule_lesson | teacher_id + lesson_date + start/end | 教师冲突检测 |
| schedule_lesson | classroom_id + lesson_date + start/end | 教室冲突检测 |
| schedule_lesson | class_id + lesson_date + start/end | 班级冲突检测 |
| class_student | student_id + status | 学员维度冲突检测（关联 schedule_lesson.class_id） |
| room_booking | classroom_id + start_time + end_time | 教室预约冲突检测 |
| attendance | lesson_id + student_id 唯一 | 防止重复考勤 |
| lesson_account | student_id + course_id 唯一 | 快速定位课时账户 |
| lesson_flow | student_id + create_time | 查询课时流水 |
| lesson_flow | source_type + source_id | 按缴费/退费/考勤源头反查流水 |
| payment_record | pay_time | 收费台账按时间统计 |
| payment_record | enrollment_id | 定位某次报名的全部缴费记录 |
| refund_record | payment_record_id / enrollment_id | 退费上限校验、报表溯源 |
| enrollment | status + hold_expire_time | 报名留位超时扫描任务 |
| parent_student | parent_user_id + student_id 唯一 | 家长学员归属校验、防重复绑定 |
| schedule_adjust_request | lesson_id / status | 调课申请按课次/状态检索 |
| teacher_salary | teacher_id + salary_month 唯一 | 防止重复生成薪资单 |
| salary_adjustment | teacher_salary_id | 定位某薪资单的全部调整记录 |

## 5. 初始化数据建议

- 五类角色账号各至少 1 个；
- 课程类型：美术、钢琴、舞蹈、书法等；
- 教师、教室、学员、班级测试数据；
- 已排课课次、考勤记录、收费记录、薪资规则；
- 统计看板所需的历史数据。
