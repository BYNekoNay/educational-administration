# 1  绪论

## 1.1  课题背景与意义

艺术培训是素质教育的重要组成部分，涵盖音乐、舞蹈、美术、体育等多种课程形态。与学科类培训相比，艺术培训机构具有鲜明的运营特征：课程类型繁多且差异显著，既有单次体验课，也有按学期、按考级阶段划分的长期课程；上课频次高，多数课程以周为单位常态化排课；授课教师多为兼职或外部合作，排班与场地调度复杂；学员以未成年人为主，请假、调课、补课频繁发生；机构收入依赖课时包销售，课时扣减与教师薪资高度关联又长期依赖人工核算。这些特征叠加在一起，使教务管理成为艺术培训机构日常运营中信息密度最高、最容易出错的环节。

在传统管理模式下，大量机构仍以 Excel 表格或纸质登记本记录学员信息、课表、考勤与收费。这种方式存在若干难以回避的痛点：其一，数据分散在多个表格与人员手中，信息流转依赖人工传递，统计具有明显的滞后性，管理者难以及时掌握招生、到课、营收与流失的真实状况；其二，课时扣减通常由教务人员按考勤手工统计，面对多名学员、多门课程的复杂组合极易出现误扣、漏扣；其三，排课往往依赖经验在纸上或电子表格中试行，教师、教室、班级三者之间的时间冲突难以在一次排布中全部暴露，冲突只能在使用过程中被动发现；其四，教师薪资以课时为基础核算，人工汇总既慢又易错，且缺乏可追溯的明细；其五，学员流失具有隐蔽性，等到续费明显下滑才被察觉时往往已错失干预窗口。

随着机构规模扩大与学员人数增长，上述手工模式的人力成本与差错成本呈非线性上升，成为制约艺术培训机构规模化、规范化运营的瓶颈。教务管理信息化由此具备了明确的工程价值：一方面，将招生、排课、考勤、课时、财务、学情等业务环节统一到同一系统中，可使业务流程标准化、数据口径一致化，从根本上消除信息孤岛；另一方面，借助自动化的课时扣减、冲突检测与薪资核算，可显著降低人工差错，提升运营效率；此外，沉淀下来的业务数据能够支撑运营看板与流失预警等决策能力，使机构由"事后统计"转向"事前干预"。

本课题以中小型艺术培训机构为服务对象，研究并实现一个覆盖"招生—排课—考勤—课时—财务—学情"全流程的教务管理平台，旨在以工程化手段解决上述实际管理难题，验证相关技术在教育培训业务场景下的可行性与有效性。

## 1.2  国内外研究现状

### 1.2.1  国外研究现状

国外在教务管理相关领域的研究起步较早，其中与本课题关联最紧密的两个方向是智能排课（university/college timetabling）与学员流失预测（dropout/retention prediction）。

在智能排课方向，课程表编排本质上是一个受多重约束的组合优化问题，长期以来是运筹学与调度领域的研究热点。Rappos 等人将大学课程排课建模为混合整数规划（Mixed-Integer Programming）问题，并通过分块求解策略在可接受时间内获得高质量的可行解，证明了精确优化方法在中等规模排课场景下的实用性[12]。Chen 等人进一步将授课教师的时间偏好纳入建模目标，采用精确优化方法求解考虑教授偏好的大学课程调度问题，表明在优化目标中引入人的主观偏好可提升排课结果的实际可接受度[13]。上述工作为本系统五维冲突检测（教师、教室、教室预约、班级、跨班学员五个时间交叉维度）与自动排课的设计提供了方法论层面的参考。

在学员流失预测方向，已有研究普遍将流失或留存视为机器学习问题，并逐步从单一成绩特征扩展到多维行为与社会经济特征。Gutierrez-Pachas 等人面向拉丁美洲高等教育场景，综合学术、社会经济与公平三类因素，结合机器学习与生存分析方法支持辍学决策，说明流失风险可由多源因素共同刻画[9]。Zhang 等人提出融合"学习模式感知"的联邦学习方法，在分布式教育数据上增强辍学预测能力，既提升了预测效果又兼顾了数据隐私[10]。Matz 等人则利用移动应用端的参与行为指标结合社会人口学特征预测学生保留率，验证了轻量级行为数据在留存预测中的价值[11]。这类研究普遍表明，到课行为、参与程度与流失风险之间存在稳定关联，为本系统以"到课沉寂度""缺勤倾向"等因子刻画学员流失风险提供了理论依据。

### 1.2.2  国内研究现状

国内面向教培机构与教务管理的研究近年来快速增多，覆盖了排课、可视化、学情分析、薪资核算、移动端、报名退费、档案管理与冲突检测等多个环节。

在排课与课时管理方面，任杰针对教培机构开发了智能排课与课时自动扣减系统，关注排课可行性与课时的自动结算[1]；黄莉研究了教室资源预约的冲突检测算法与调度方案，为排课过程中的资源冲突识别提供了算法支撑[8]。在运营可视化方面，温雅基于 Vue 与 ECharts 实现了培训机构经营数据的可视化，展示了前端可视化框架在教务统计看板中的直接应用价值[2]。在学情分析方面，石峰设计了学员学情多维度大数据分析模型，从多维度刻画学员的学习状态[3]。在财务与薪资方面，贺敏基于 Spring Boot 实现了教师课时薪资自动核算模块，验证了后端框架支撑薪资自动化的可行性[4]。在移动端方面，周佳开发了家长端小程序的课表查询与上课消息推送功能，说明移动端是连接家长与教务信息的关键入口[5]。在业务流程方面，刘畅设计了培训机构学员报名、转班、退费流程的闭环，强调业务流程的完整性[6]；陈瑶研究了考级信息归档与学员成长档案的数据库建模，为学情档案的数据组织提供了参考[7]。

综合来看，国内外现有研究多聚焦单一算法点或单一业务环节，例如单独研究排课优化、单独研究流失预测，或单独研究某一端（管理端或移动端）的某项功能。对于中小型艺术培训机构而言，这类"点状"成果难以直接拼装为一个可用、可靠、可维护的整体系统。其突出短板在于：缺少面向该类机构、覆盖"招生—排课—考勤—课时—财务—学情"全业务链条的工程化落地系统；缺少将排课、考勤、课时、薪资、预警等环节以统一数据模型串联并形成业务闭环的设计；也缺少在并发一致性、权限隔离与可维护性等工程质量属性上的系统性保障。

上述研究缺口正是本课题的出发点：在吸收既有算法与实现经验的基础上，以一个完整、可上线的工程系统为目标，将分散的研究成果整合到统一的业务流程与数据模型中，使艺术培训机构的教务管理真正实现数字化、自动化与可决策化。

## 1.3  研究内容与目标

本课题的研究目标是构建一个面向艺术培训机构的全流程教务管理平台，将招生报名、课程班级管理、智能排课与调课、课堂考勤、课时自动扣减、收费退费、教师薪资核算与运营统计等环节纳入同一个系统，支持学员家长、授课教师、教务管理员、财务管理员与超级管理员五类角色协同工作。

在技术路线上，系统采用前后端分离的 B/S 架构：管理后台以 Vue 3 与 Element Plus 构建，承载课程、排课、财务等数据密集型页面的复杂交互；移动端以 uni-app 跨平台框架实现家长端与教师端，覆盖课表查看、报名缴费、考勤打卡与消息接收等高频轻量场景；后端以 Spring Boot 3.2.5 与 MyBatis-Plus 3.5.7 提供统一业务接口，数据持久化于 MySQL 8.0，并通过 Flyway 进行版本化数据库迁移。身份认证采用 JWT 无状态方案，配合基于角色的接口鉴权实现五类角色的权限隔离。

在业务设计上，本课题重点解决四类关键问题：一是以"报名决策快照 + 版本校验"保证报名决策数据的一致性；二是以五维时间交叉冲突检测（教师、教室、教室预约、班级、跨班学员）与拖拽快速调课提升排课易用性，并以复合乐观并发控制防止同状态并发编辑相互覆盖；三是以状态机与并发控制相结合的核算体系实现教师薪资自动核算；四是以可解释的多因子规则构建学员流失预警，将运营统计升级为流失干预决策。

系统的最终目标是在完成功能开发与分层测试后，以容器化方式部署上线并在生产环境稳定运行，实现从需求分析、设计实现、测试验收到生产上线的完整交付。

## 1.4  论文组织结构

论文共分为五章，另有总结、参考文献、附录与致谢，各章内容安排如下：

第 1 章绪论，阐述艺术培训机构教务管理的背景与意义，综述国内外在智能排课与学员流失预测等方向的研究现状并指出研究缺口，明确本课题的研究内容与目标，最后给出论文的整体组织结构。

第 2 章相关技术介绍，分别介绍 Vue 3、Element Plus、uni-app、Spring Boot、MyBatis-Plus、MySQL、Flyway、JWT、ECharts 与 Apache POI 等关键技术，并说明其在系统中的选型理由。

第 3 章系统需求分析与总体设计，从功能需求与非功能需求两个维度开展需求分析，给出系统总体架构、功能模块划分、数据库设计与部署架构，为后续详细实现奠定设计基础。

第 4 章系统详细设计与实现，围绕报名退费、排课调课、考勤课时、财务薪资、学情考级、运营看板与流失预警以及移动端功能，阐述核心模块的设计思路与关键实现。

第 5 章系统测试，说明分层测试环境与策略，从功能测试、并发一致性测试、安全测试与可靠性测试等方面验证系统的正确性与健壮性，并给出测试结论。

总结部分归纳系统的主要工作与创新点，分析当前存在的不足并提出后续改进方向。
