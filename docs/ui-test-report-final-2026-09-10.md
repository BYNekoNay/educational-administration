## 二、执行过程与三次重大发现

### 2.1 出网代理拦截（测试环境侧，非系统缺陷）

| 问题 | 详情 | 解决 |
|------|------|------|
| 403 `ip access not allowed` | 全局 HTTP 代理（`Proxy-1.14.0` / gost 上游）按目标 IP 白名单拦截，`101.35.239.218` 不在其中；响应耗时 0.01s，请求根本未到达服务器（服务器 Caddy 访问日志中该出口 IP `39.96.162.41` 命中 0 条） | 测试环境将目标 IP 加入 gost bypass 列表 |

**判据备忘**：本系统响应头为 `Server: Caddy, nginx/1.27.5`；`Proxy-1.14.0` 非本服务标识。服务器侧经核查无任何 IP 白名单机制（Caddy/nginx 无过滤规则、iptables 仅 8 条云镜恶意 IP 拒绝、代码库无 IP 校验逻辑）。

### 2.2 移动端部署了 7 月旧产物（部署缺陷，已修复）

| 项 | 内容 |
|----|------|
| 现象 | 线上 H5 缺少 v1.3 全部移动端功能（教师请假审批、课表真实化、消息角标、学情上下文） |
| 根因 | 首次部署直接复用本地现存产物 `dist/build/h5-release`（构建于 07-30），未校验新鲜度 |
| 证据 | 旧产物不含 `leave-audit` / `schedule-summary` / `unread-count`；对照组 `admin-web/dist` 为 09-08 新产物、功能正常 |
| 修复 | 重新构建（`VITE_BASE=/mobile/ npm run build:h5`）→ assets 45→51、含全部 v1.3 页面 → 重建 web 镜像重新部署 |

### 2.3 构建产物缺失 static 目录（构建缺陷，自 2026-07 潜伏，已修复）

| 项 | 内容 |
|----|------|
| 现象 | tabBar 图标 `/mobile/static/tab/*.png` 全部 404，界面显示图片占位符（ISSUE-005） |
| 根因 | `vite.config.ts` 的 `outDir` 被设为非默认 `dist/build/h5-release`（历史原因：`mp-weixin` 目录曾被外部进程锁定），而 `vite-plugin-uni` 仍把 `src/static` 复制到默认路径 `dist/build/h5/static`，两条路径不一致 |
| 修复 | `vite.config.ts` 新增 `copy-uni-static-to-outdir`（`closeBundle` 钩子）补复制到真实输出目录 |
| 验证 | 6 个图标线上全部 200 |
