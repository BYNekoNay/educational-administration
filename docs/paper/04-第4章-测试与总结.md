## 4.3 非功能性测试

### 4.3.1 并发一致性测试

针对系统核心并发操作设计并发测试，重点验证乐观并发控制的有效性。测试覆盖快速调课"同状态并发编辑"场景（T09）：由于快速调课不翻转状态字段，仅凭状态条件无法拦截同状态并发，系统在乐观更新条件中追加旧时间条件，使并发第二笔更新失败并返回 409。回归测试还捕获更新条件参数，防止将来被改回仅有"id + 状态"的弱并发保护。退费审核、薪资确认/发放/撤销、课时扣减等操作同样以乐观更新行数校验保证并发正确性。

### 4.3.2 安全测试

系统安全性测试覆盖以下方面：其一，越权访问防护——通过自动化接口测试验证五类角色共 21 个授权端点可用、5 类越权请求被拒绝（返回无权限提示），角色间数据不可越权访问；其二，身份认证安全——接口统一要求 JWT 令牌，登录失败、令牌过期与用户被禁用场景下均正确拒绝；其三，输入与上传安全——上传文件同时校验扩展名、Content-Type 与文件头魔数签名，防止伪装文件上传；其四，生产配置校验——系统在生产环境启动时校验数据库密码、JWT 密钥强度与 CORS 来源白名单，拒绝默认弱配置启动。

### 4.3.3 可靠性测试

可靠性方面：其一，数据库结构一致性——引入 Flyway 版本化迁移后，迁移脚本具备幂等性，支持存量数据库平滑升级，并通过高价值数据不变量检查（孤儿收费/退费记录）作为部署硬门禁；其二，数据可恢复性——建立 MySQL 与上传附件的加密备份与恢复演练机制，可验证备份可用；其三，发布可验证性——部署流水线设置后端与前端测试门禁、登录接口冒烟探测与容器健康检查，失败即阻止发布；其四，系统可观测性——提供健康/就绪探针、业务指标与请求关联日志，便于线上问题定位。

# 总  结

本次课程设计完成了基于 Vue 3 + uni-app + Spring Boot + MySQL 架构的艺术培训机构全流程教务管理平台的设计与实现。系统覆盖招生报名、课程班级、智能排课与调课、课堂考勤、课时自动扣减、收费退费、教师薪资自动核算、学情考级与运营数据统计的完整业务闭环，支持家长、教师、教务、财务与超级管理员五类角色协同工作，满足了艺术培训机构数字化教务管理的实际需求。

在系统设计与实现过程中，主要解决了以下几方面问题：其一，针对移动端报名场景的多接口串行请求与决策数据不一致问题，设计了"报名决策快照 + If-Match 版本校验"的一致性方案；其二，针对教务排课的易用性问题，实现了大课表拖拽快速调课，并通过"状态 + 旧时间"复合乐观条件解决了同状态并发编辑相互覆盖的问题；其三，针对教师薪资人工核算易错问题，建立了按课程薪资规则自动核算并配合状态机与并发控制的核算体系；其四，针对机构运营"只看历史、难防流失"的问题，实现了可解释的多因子流失预警引擎，将统计升级为决策；其五，引入 Flyway 版本化迁移、加密备份恢复、发布门禁与业务可观测性等手段，提升了系统的可靠性与可维护性。

同时，系统仍存在一些不足之处。首先，在功能层面，当前支付与短信通知为模拟实现，尚未接入真实支付网关与短信服务商；其次，在性能层面，系统当前为单机部署，未引入缓存层，面对较大并发时存在优化空间；最后，在智能化层面，流失预警采用规则打分而非机器学习模型，后续可基于积累数据引入更精细的流失预测算法。上述不足将作为后续改进方向，不断完善系统功能与性能。
