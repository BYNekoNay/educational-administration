# 附录 A  软件使用说明书

## A.1 运行环境

### A.1.1 硬件环境

| 项目 | 最低配置 | 推荐配置 |
|------|---------|---------|
| CPU | 双核 2.0 GHz | 四核 2.5 GHz 及以上 |
| 内存 | 4 GB | 8 GB 及以上 |
| 磁盘 | 20 GB 可用空间 | 40 GB 及以上 |
| 网络 | 可访问局域网/公网 | 宽带接入 |

### A.1.2 软件环境

| 类别 | 软件 | 版本 |
|------|------|------|
| 操作系统 | Windows / Linux / macOS | Windows 10+ 或 Ubuntu 22.04 |
| 后端运行 | JDK | 17 |
| 数据库 | MySQL | 8.0+（端口 3306） |
| 构建工具 | Maven | 3.9+ |
| 前端运行 | Node.js / npm | 18+ / 9+ |
| 浏览器 | Chrome / Edge 等现代浏览器 | 最新稳定版 |

## A.2 系统配置

### A.2.1 数据库初始化

创建数据库并导入脚本：

```bash
mysql -u root -p < sql/schema.sql   # 建表
mysql -u root -p < sql/data.sql     # 演示数据
```

数据库名 edu_admin。数据库结构升级由 Flyway 在应用启动时自动执行。

### A.2.2 后端配置

后端通过环境变量注入关键配置，生产环境启动命令示例：

```bash
JWT_SECRET=<至少32字节的随机密钥> DB_PASSWORD=<数据库密码> \
java -jar eduadmin.jar --server.port=8080
```

关键环境变量说明如表 A.1 所示。

表 A.1  后端环境变量

| 变量 | 说明 | 默认 |
|------|------|------|
| DB_PASSWORD | 数据库密码 | 无（生产必填） |
| JWT_SECRET | JWT 签名密钥（≥32 UTF-8 字节） | 无（生产必填） |
| APP_CORS_ALLOWED_ORIGINS | CORS 允许来源白名单 | 无（生产必填） |
| SERVER_PORT | 服务端口 | 8080 |

> 生产环境由 ProductionConfigurationValidator 在启动时校验上述配置，弱密钥或默认密码将拒绝启动。

### A.2.3 前端配置

管理后台开发模式通过 Vite 代理将 `/api` 转发至后端 8080 端口；生产模式由 Nginx/Caddy 反向代理。移动端 H5 产物由 Web 服务器托管。

## A.4 系统功能操作说明

系统按角色提供如下主要操作：

1. **学员家长（移动端）**：查看课程套餐并在线报名、查看周课表与学情详情、查询剩余课时与消耗流水、接收上课提醒与调课通知、发起请假与退费申请、查看缴费记录。
2. **授课教师（移动端）**：查看个人授课课表、对课次进行课堂考勤（到课/迟到/请假/缺勤）、发布作业并点评学员表现、查看个人月度课时统计、发起调课申请。
3. **教务管理员（管理后台）**：维护课程、班级与课节时段，执行批量/自动排课，在大课表拖拽快速调课并审核教师调课申请，审核报名，管理学员档案、分班与转班，维护考级项目与成绩。
4. **财务管理员（管理后台）**：登记收费与续费、审核退费、查看课时消耗报表、配置薪资规则并核算/确认/发放教师薪资、查看营收统计并导出报表。
5. **超级管理员（管理后台）**：管理用户、角色与权限、配置机构信息、发布公告、查看全局运营看板与流失预警清单、查看操作日志。
