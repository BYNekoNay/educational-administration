# 艺术培训机构全流程教务管理平台的设计与实现

## 摘  要

随着艺术培训行业的快速发展，培训机构普遍面临课程类型多、上课频次高、教师排班复杂、学员请假调课频繁、课时扣减与教师薪资依赖人工核算等管理难题。传统的 Excel 或纸质登记方式数据分散、统计滞后，容易出现课时误扣、排课冲突与薪资核算错误，制约机构规模化运营。

针对上述问题，本文设计并实现了面向艺术、兴趣类培训机构的全流程教务管理平台。系统采用前后端分离的 B/S 架构，管理后台基于 Vue 3 与 Element Plus 构建，移动端基于 uni-app 跨平台框架实现，后端采用 Spring Boot 3.2.5 与 MyBatis-Plus 3.5.7 提供统一业务接口，数据存储于 MySQL 8.0。系统覆盖招生报名、课程班级管理、智能排课与调课、课堂考勤、课时自动扣减、收费退费、教师薪资自动核算与运营数据统计的完整业务闭环，支持学员家长、授课教师、教务管理员、财务管理员与超级管理员五类角色协同工作。系统实现了基于多因子评分的学员流失预警模型，并以版本化迁移、加密备份、发布门禁与业务可观测性等手段保障系统的可靠性与安全性。

系统采用 JUnit 5、Mockito 与 Vitest 建立分层测试体系，后端 464 个单元测试、管理端 118 个与移动端 6 个测试全部通过，并经浏览器验收确认主要业务流程可用。测试结果表明系统功能完备、并发控制可靠、权限隔离正确，能够满足艺术培训机构数字化教务管理需求。

**关键词**：教务管理；智能排课；课时管控；薪资核算；流失预警

## ABSTRACT

With the rapid development of the art training industry, training institutions generally face management difficulties such as numerous course types, high class frequency, complex teacher scheduling, frequent leave and class-adjustment requests from students, as well as manual accounting of lesson deduction and teacher salaries. Traditional Excel or paper-based registration leads to scattered data, delayed statistics, and is prone to errors in lesson deduction, scheduling conflicts and salary calculation, which restricts the scaled operation of institutions.

To address these problems, this paper designs and implements a full-process educational administration management platform for art training institutions. The system adopts a front-end and back-end separated B/S architecture. The management console is built with Vue 3 and Element Plus, the mobile terminal is implemented with the uni-app cross-platform framework, and the back end uses Spring Boot 3.2.5 and MyBatis-Plus 3.5.7 to provide unified business APIs, with data stored in MySQL 8.0. The system covers a complete business closed loop including enrollment and payment, course and class management, intelligent scheduling and adjustment, class attendance, automatic lesson deduction, charges and refunds, automatic teacher salary accounting, and operational statistics, supporting collaboration among five roles: parents, teachers, educational administrators, financial administrators and super administrators. A multi-factor student churn warning model is implemented, and the reliability and security of the system are guaranteed by versioned database migration, encrypted backup, release gates and business observability.

A layered testing system is established with JUnit 5, Mockito and Vitest. All 464 back-end unit tests, 118 admin-web tests and 6 mobile tests pass, and browser acceptance confirms that the main business processes are usable. Test results show that the system is functionally complete, reliable in concurrency control and correct in permission isolation, and can satisfy the digital educational administration needs of art training institutions.

**Keywords**: Educational Administration; Intelligent Scheduling; Lesson Management; Salary Accounting; Churn Warning

# 1  相关技术介绍及选型

## 1.1 相关技术介绍

### 1.1.1 前端框架 Vue 3 与 Element Plus

Vue 3 是当前主流的渐进式前端框架，采用组合式 API（Composition API）与响应式数据模型，配合 Vite 开发服务器可实现模块热更新与快速构建。Element Plus 是基于 Vue 3 的桌面端组件库，提供表格、表单、弹窗、分页、日期选择等企业级组件，能够有效支撑教务、财务等管理场景下复杂表格与表单的快速开发。本系统管理后台采用 Vue 3 + Element Plus + Pinia 状态管理 + TypeScript 的组合，其中 Pinia 负责登录态、角色权限等全局状态的管理，TypeScript 为复杂数据模型提供静态类型保障。

### 1.1.2 跨平台框架 uni-app

uni-app 是一套使用 Vue 语法开发跨平台应用的框架，一套代码可编译运行到 H5、微信小程序与 Android/iOS App 等多个平台。对于家长端与教师端这类以移动端高频轻量操作为主的场景，uni-app 能够显著降低多端重复开发成本。本系统移动端基于 uni-app 与 uView Plus 组件库实现家长端与教师端页面，业务规则统一由后端接口提供，保证各端数据一致。

### 1.1.3 后端框架 Spring Boot 与 MyBatis-Plus

Spring Boot 是当前主流的 Java 后端快速开发框架，遵循"约定优于配置"理念，通过自动装配与起步依赖大幅简化项目搭建。Spring Boot 3.2.5 基于 JDK 17，内置嵌入式 Web 容器，支持构建可独立运行的 JAR 包。MyBatis-Plus 是 MyBatis 的增强工具，在保留 MyBatis 灵活 SQL 能力的同时，提供通用 CRUD、逻辑删除、乐观锁、分页插件等开箱即用的能力，可有效减少业务层样板代码。本系统利用 MyBatis-Plus 的逻辑删除与乐观锁机制支撑课时账户、退费审核等关键数据的并发安全。

### 1.1.4 数据库 MySQL

MySQL 是应用广泛的开源关系型数据库，支持 InnoDB 事务引擎与行级锁，具备良好的事务一致性与并发控制能力。本系统采用 MySQL 8.0 存储业务数据，共设计 34 张表覆盖用户权限、学员课程、排课调课、考勤学情、课时流水、财务薪资、考级通知与运营管理八大业务域。数据库结构变更通过 Flyway 版本化迁移管理，保证多环境数据库状态的一致性。

### 1.1.5 认证与安全技术 JWT

JWT（JSON Web Token）是一种无状态的身份认证方案，服务端在登录成功后签发包含用户标识与角色信息的签名令牌，客户端在后续请求中携带该令牌，服务端验签后即可确认身份。相比传统 Session 方案，JWT 天然适合前后端分离架构与移动端场景。本系统使用 HMAC-SHA256 算法对 JWT 进行签名，通过自定义拦截器统一完成令牌校验与基于角色的接口鉴权。

### 1.1.6 数据可视化与报表技术 ECharts、Apache POI

ECharts 是基于 JavaScript 的开源可视化图表库，提供折线图、柱状图、饼图等丰富图表类型。本系统使用 ECharts 在运营数据看板中呈现月度课时趋势、营收趋势与到课率趋势等统计图表。Apache POI 是 Java 处理 Office 文档的开源类库，本系统基于其 SXSSF 组件实现收费台账、课时消耗、薪资结算等报表的 Excel 导出。

## 1.2 技术选型

本系统在技术选型时主要遵循以下原则：技术成熟稳定、社区支持广泛、前后端职责清晰、开发效率与运行性能兼顾。具体选型如下。

### （1）前端：Vue 3 + Element Plus（管理后台）与 uni-app（移动端）

选择 Vue 3 作为管理后台基础框架，主要基于以下考虑：其一，Vue 3 的组合式 API 相比选项式 API 更适合复杂业务逻辑的组织与复用，配合 TypeScript 可显著提升可维护性；其二，Element Plus 组件库与后台管理系统常见的中后台交互模式高度契合，可快速搭建课程管理、排课、财务等数据密集型页面；其三，Vue 3 与 Vite 构建工具的搭配能提供流畅的开发体验。

移动端选择 uni-app，主要基于以下考虑：首先，家长与教师的使用场景以移动端高频轻量操作为主，uni-app 支持一套代码同时发布 H5 与微信小程序，覆盖成本低；其次，uni-app 使用 Vue 语法，与团队的技术栈保持一致，降低学习与维护成本；最后，家长端与教师端通过统一的后端接口与 Web 管理后台交互，避免业务规则在两端重复实现。

### （2）后端：Spring Boot + MyBatis-Plus

选择 Spring Boot 作为后端开发框架，主要基于以下考虑：首先，Spring Boot"约定优于配置"的开发模式能大幅减少配置样板代码，通过起步依赖与自动装配快速完成工程搭建；其次，Spring Boot 3.x 基于 JDK 17，生态成熟，提供定时任务、事件机制、Actuator 健康检查与指标暴露等能力，为业务调度、发布探针与可观测性建设提供支持；最后，其内置 Web 容器使系统可以构建为独立运行的 JAR 包，便于容器化部署。

在持久层框架方面，选择 MyBatis-Plus 作为 ORM 框架，主要基于以下考虑：MyBatis-Plus 在保留手写 SQL 灵活性的同时，提供通用 CRUD、逻辑删除、乐观锁、分页插件等能力，能够显著减少数据访问层样板代码；其乐观锁机制为本系统课时扣减、薪资结算等"读-改-写"型并发操作提供了统一的并发控制手段。

### （3）数据库：MySQL 8.0

选择 MySQL 作为数据库管理系统，主要基于以下考虑：首先，MySQL 作为开源数据库无需许可费用，成本可控；其次，MySQL 在 Web 应用中生态成熟，InnoDB 引擎的事务与行级锁能力满足教务业务对数据一致性的要求；最后，本系统单机部署的规模下，MySQL 的性能与运维复杂度均处于合适区间，配合 Flyway 可实现对 34 张表结构的版本化管理。

### （4）辅助技术

除上述核心技术外，本系统还使用了以下辅助技术：

① 认证与鉴权：JWT（HMAC-SHA256 无状态签名）配合自定义 Spring 拦截器实现登录态校验与基于 @RequireRole 注解的角色级接口鉴权，支持五类角色的权限隔离与越权访问拦截；

② 状态管理：管理后台使用 Pinia 管理登录用户信息、角色码与权限集，页面依据角色动态渲染可操作入口，实现前后端双重的权限控制；

③ 数据库迁移：使用 Flyway 对数据库结构变更进行版本化管理，生产环境启动时自动执行迁移脚本，保证开发、测试与生产环境的数据库结构一致；

④ 可视化与导出：使用 ECharts 呈现运营统计图表，使用 Apache POI（SXSSF）实现收费台账、课时消耗、薪资结算与流失预警名单的 Excel 报表导出；

⑤ 开发与构建工具：后端使用 Maven 3.9 管理依赖与构建，管理后台使用 Vite 5 与 npm 完成开发与构建，移动端使用 uni-app CLI 构建 H5 与小程序产物；

⑥ 测试工具：后端使用 JUnit 5 与 Mockito 建立单元测试体系，管理后台使用 Vitest 与 Vue Test Utils 建立组件测试体系，移动端使用 Vitest 对报名决策等核心逻辑进行测试。
