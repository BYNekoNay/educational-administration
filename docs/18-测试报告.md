### 7.2 重点缺陷复盘

**DEF-01　拖拽快速调课时同状态并发可被覆盖**
现象：两笔调课请求读到相同的课次状态，均通过状态校验并成功写入，先提交者的修改被静默覆盖。
根因：CAS 仅以 `status` 为前置条件，而调课前后状态同为 1（待上课），条件恒真。
修复：在乐观条件中追加「原日期 + 原起止时间」，第二笔更新影响行数为 0 时返回冲突；并补充回归测试防止回退。

**DEF-02　生产环境移动端缺少 v1.3 功能**
现象：上线后移动端功能落后于本地版本。
根因：首次部署复用了本地七月底构建的旧产物，未校验产物新鲜度。
修复：重新构建部署，并在发布流程中明确产物校验。

**DEF-03　构建产物缺失静态资源目录导致底部导航图标 404**
现象：移动端底部 tabBar 图标全部显示为占位符。
根因：构建产物未包含静态资源目录。
修复：在 `vite.config.ts` 增加 `closeBundle` 复制钩子；重新构建后图标恢复，接口验收 38 项复验全过。

**DEF-04　考级报名状态机缺少并发保护**
现象：审核结果可被陈旧页面提交静默覆盖，已通过的终态可被改回未通过。
根因：该处是全库唯一使用「读快照 → 校验 → 整体回写」的状态机，UPDATE 条件只有主键。
修复：改为带状态前置条件的原子更新，影响行数 0 时返回 409；新增 `ExamSignupConcurrencyTest` 三个用例守护，并做了「去掉 CAS 后测试确实变红」的变异验证。

**DEF-05　移动端与后台取当日日期出现时区偏差**
现象：UTC+8 下每日 00:00–08:00 取到前一日；每月 1 日 08:00 前薪资核算默认月份为上个月。
根因：前端用 `new Date().toISOString()` 取日期，得到的是 UTC；后端容器时区本身正确。
修复：新增 `utils/date.ts` / `utils/date.js` 提供本地时区取值，四处调用点统一改用。
