# 文档说明

## 1. 文档集概述

本目录（`docs/`）汇总了“艺术培训机构全流程教务管理平台的设计与实现”毕业设计项目的软件工程文档。文档集参考 GB/T 8567《计算机软件文档编制规范》的常见文档类型，并结合本科毕业设计任务书要求进行裁剪，覆盖问题定义、可行性研究、需求分析、概要设计、详细设计、测试、软件功能说明、开发实施与部署计划等内容。

本项目面向艺术、兴趣类培训机构，围绕招生报名、课程班级、智能排课、课堂考勤、课时扣减、学员学情、收费退费、教师薪资和运营数据统计建立完整业务闭环。
