## 一、背景

## 二、项目核心算法清单（摘自 12-核心算法设计文档）

| # | 核心算法 | 实现要点 |
|:--:|---|---|
| A | 排课**冲突检测** | 时间区间重叠 `start1<end2 且 end1>start2`；教师/教室/教室预约/班级/跨班学员**五维** + 容量校验 |
| B | **批量排课** | 约束满足 + 贪心生成；按容量升序取首个无冲突教室；行锁串行化；教师单日课次上限 |
| C | **课时自动扣减** | 考勤状态机；`FOR UPDATE` 或 **version 乐观锁重试**；考勤+账户+流水同事务 |
| D | **教师薪资自动核算** | 课次→单价规则映射；代课系数；结算快照 + 调整记录 |
| E | **退费金额计算** | 可退课时×单价−违约金 + **已缴费上限**强制校验 |
| F | **学员流失预警** | 可解释多因子（到课沉寂度、缺勤倾向），非 ML |
| G | 统计 / 可视化看板 | 多维聚合 + ECharts |
| H | 移动端 | uni-app 课表、考勤、消息 |
