# 前端公共组件使用说明

> 对应 `docs/99-代码文档合规性审查报告.md` 的 **M2** 项（前端缺少 6 个文档规划的公共组件）。
> 组件位置：`admin-web/src/components/`，统一从 `@/components` 引入。

| 组件 | 用途 | 对应文档 §3.6 |
|---|---|---|
| `DataTable` | 分页表格 + 加载态 + 空态 + 自定义单元格 | 分页表格+筛选+加载态+空态 |
| `FormDialog` | 新增/编辑弹窗表单（schema 驱动） | 新增/编辑弹窗表单 |
| `ScheduleCalendar` | 课表周视图（按星期聚合课次） | 课表日历/周视图 |
| `UploadFile` | 作业附件、证书图片上传（带鉴权） | 附件/图片上传 |
| `ChartPanel` | ECharts 图表面板 | ECharts 图表面板 |
| `ExportButton` | 报表导出按钮（带鉴权、支持后端命名） | 报表导出按钮 |

## 1. DataTable

受控组件：父组件持有 `data / total / pageNum / pageSize`，通过事件回传分页与排序。

```vue
<script setup lang="ts">
import { ref } from 'vue'
import { DataTable, type TableColumn } from '@/components'

const data = ref<any[]>([])
const total = ref(0)
const pageNum = ref(1)
const pageSize = ref(10)

const columns: TableColumn[] = [
  { prop: 'id', label: 'ID', width: 60, sortable: 'custom' },
  { prop: 'name', label: '姓名', sortable: 'custom' },
  { prop: 'status', label: '状态', width: 90, formatter: (r) => (r.status === 1 ? '在读' : '停课') }
]

function load() { /* 调接口，回填 data / total */ }
function onPageChange(p: number, s: number) { pageNum.value = p; pageSize.value = s; load() }
function onSortChange({ prop, order }: any) { /* 服务端排序 */ }
</script>

<template>
  <DataTable
    :data="data"
    :columns="columns"
    :total="total"
    :page-num="pageNum"
    :page-size="pageSize"
    :loading="false"
    @page-change="onPageChange"
    @sort-change="onSortChange"
  >
    <!-- 自定义单元格：slot 名为 cell-<prop> -->
    <template #cell-status="{ row }">
      <el-tag :type="row.status === 1 ? 'success' : 'warning'">{{ row.status === 1 ? '在读' : '停课' }}</el-tag>
    </template>
    <!-- 操作列 -->
    <template #actions="{ row }">
      <el-button size="small" @click="edit(row)">编辑</el-button>
    </template>
  </DataTable>
</template>
```

- 未提供 `cell-<prop>` 插槽时，默认直接显示原始值或 `formatter` 结果。
- 提供 `#actions` 插槽即自动渲染右侧操作列。

## 2. FormDialog

schema 驱动：通过 `fields` 描述字段，自动渲染输入控件；打开时拷贝 `form` 为内部模型，保存时回传组装好的对象。

```vue
<script setup lang="ts">
import { ref } from 'vue'
import { FormDialog, type FormField } from '@/components'

const visible = ref(false)
const saving = ref(false)
const current = ref<any>({})

const fields: FormField[] = [
  { prop: 'name', label: '姓名', required: true },
  { prop: 'gender', label: '性别', type: 'select', clearable: false,
    options: [{ label: '男', value: 1 }, { label: '女', value: 2 }] },
  { prop: 'birthday', label: '出生日期', type: 'date' },
  { prop: 'status', label: '状态', type: 'select',
    options: [{ label: '在读', value: 1 }, { label: '停课', value: 2 }] }
]

function open(row?: any) {
  current.value = row ? { ...row } : {}
  visible.value = true
}
async function onSave(form: Record<string, any>) {
  saving.value = true
  try { /* 调 create / update 接口 */ visible.value = false } finally { saving.value = false }
}
</script>

<template>
  <FormDialog
    v-model="visible"
    title="学员信息"
    :fields="fields"
    :form="current"
    :saving="saving"
    @save="onSave"
  />
</template>
```

字段类型支持：`input`（默认）、`textarea`、`number`、`select`、`date`、`switch`；`required` 字段在保存前做空值校验。

## 3. ScheduleCalendar

按星期聚合课次的周视图。

```vue
<script setup lang="ts">
import { ScheduleCalendar, type ScheduleItem } from '@/components'

const lessons: ScheduleItem[] = [
  { id: 1, title: '钢琴一对一', dayOfWeek: 1, start: '09:00', end: '10:00', location: 'A201' },
  { id: 2, title: '少儿绘画', dayOfWeek: 3, start: '14:00', end: '15:30', color: '#E91E63' }
]
</script>

<template>
  <ScheduleCalendar :lessons="lessons" />
</template>
```

- `dayOfWeek`：1=周一 … 7=周日。
- 同一天的课次按 `start` 升序排列。

## 4. UploadFile

带 JWT 鉴权的文件上传（走 `request` 拦截器注入 `Bearer` 头）。

```vue
<script setup lang="ts">
import { ref } from 'vue'
import { UploadFile } from '@/components'

const urls = ref<string[]>([])
</script>

<template>
  <UploadFile
    v-model="urls"
    action="/api/edu/attachments/upload"
    accept=".jpg,.png,.pdf"
    :limit="3"
    tip="支持 jpg/png/pdf，最多 3 个"
  />
</template>
```

- 后端成功响应约定：`{ code: 0, data: { url: '...' } }`（或 `data.url` / `data.fileUrl`）。
- `v-model` 为已上传 URL 字符串数组。

## 5. ChartPanel

ECharts 图表面板，传入标准 `option` 即可。

```vue
<script setup lang="ts">
import { ref } from 'vue'
import { ChartPanel } from '@/components'

const option = ref({
  tooltip: {},
  xAxis: { type: 'category', data: ['一月', '二月', '三月'] },
  yAxis: { type: 'value' },
  series: [{ type: 'bar', data: [120, 200, 150] }]
})
</script>

<template>
  <ChartPanel :option="option" title="月度营收" height="300px" />
</template>
```

## 6. ExportButton

带鉴权的报表导出按钮，自动处理 blob 下载与后端文件名。

```vue
<script setup lang="ts">
import { ExportButton } from '@/components'
</script>

<template>
  <ExportButton
    url="/api/edu/students/export"
    :params="{ keyword: '' }"
    filename="学员名单.xlsx"
    label="导出名单"
  />
</template>
```

- 使用独立 axios 实例（仅注入鉴权头），避免 blob 响应被统一响应拦截器误判。
- 若后端返回 `Content-Disposition: filename=xxx.xlsx`，优先采用该文件名。
- 支持 `method="post"` 将 `params` 放入请求体。
