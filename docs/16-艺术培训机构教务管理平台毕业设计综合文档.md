# 艺术培训机构全流程教务管理平台毕业设计综合文档

> **版本状态**：v0.8 规划版，基于仓库根目录 `项目.md` 编制，并参考 `docs/` 目录现有软件工程文档的结构进行整理。本文档用于毕业设计前期需求分析、系统设计、论文撰写与答辩准备，后续应随实际代码、数据库脚本和测试结果进行一致性回检。

## 1. 项目概述

### 1.1 项目名称

艺术培训机构全流程教务管理平台的设计与实现。

### 1.2 研究方向

本课题面向艺术、兴趣类培训机构的日常运营场景，研究教务管理数字化、课时管控、教师薪资核算、学员学情记录与机构经营数据分析等问题，设计并实现一套前后端分离的综合教务管理平台。

### 1.3 项目背景

艺术培训机构通常存在课程类型多、上课频次高、教师排班复杂、学员请假调课频繁、课时扣减与教师薪资统计依赖人工核算等问题。传统 Excel 或纸质登记方式容易造成数据分散、统计滞后、课时误扣、排课冲突和薪资核算错误，不利于机构规模化运营。

本系统通过信息化平台将招生报名、课程班级、排课考勤、课时消耗、学员学情、收费退费、教师薪资和运营统计统一管理，提高机构教务处理效率和数据准确性，为管理者提供可视化运营决策依据。

### 1.4 建设目标

- 建立面向家长、教师、教务、财务、超级管理员五类用户的角色化管理平台；
- 采用 **uni-app 移动端 + Vue3 管理后台 + Spring Boot 后端** 的组合架构；
- 家长端、教师端聚焦移动端操作体验，教务、财务、管理员聚焦 PC 管理后台效率；
- 实现报名缴费、课程排班、课堂考勤、课时扣减、作业点评、考级管理、收费退费、薪资结算等核心业务闭环；
- 提供招生、到课率、课时消耗、营收、教师工作量等多维度数据统计与图表展示；
- 形成完整的软件工程文档、测试报告、数据库脚本、可运行系统和毕业论文材料。

## 2. 可行性分析

### 2.1 技术可行性

系统采用 **Spring Boot + uni-app 移动端 + Vue3 管理后台** 前后端分离架构。后端使用 Spring Boot 提供 RESTful API，结合 MyBatis-Plus 或 MyBatis 进行数据访问，使用 MySQL 存储业务数据，使用 Redis 支撑缓存、课表提醒、排课冲突检测辅助数据和高频统计。

- **uni-app** 适合家长和教师移动端高频使用场景，可运行在 H5、微信小程序或 App；
- **Vue3 + Element Plus** 适合教务、财务和管理员后台的复杂表格、表单和统计图表；
- **Spring Boot** 统一承载五类角色业务规则，避免移动端与后台各自实现业务逻辑。

上述技术生态成熟、资料丰富，适合本科毕业设计周期内完成。

## 3. 用户角色与终端分配

| 角色 | 推荐终端 | 核心诉求 |
|---|---|---|
| 学员家长 | uni-app 移动端 | 报名、查看课表、学情、课时、通知 |
| 授课教师 | uni-app 移动端 | 查看课表、考勤、作业、点评、课时统计 |
| 教务管理员 | Vue3 管理后台 | 课程、班级、排课、学员、考级管理 |
| 财务管理员 | Vue3 管理后台 | 收费、退费、课时、薪资、营收统计 |
| 超级管理员 | Vue3 管理后台 | 用户权限、机构配置、公告、全局看板 |

## 4. 总体架构设计

系统整体分为两个终端工程和一个统一后端：

- `mobile-uniapp`：家长端、教师端；
- `admin-web`：教务端、财务端、超级管理员端；
- `backend`：Spring Boot 统一 API。

这种分工既符合真实培训机构的使用习惯，也便于毕业设计从“终端适配”和“角色分工”两个维度展开说明。

## 5. 移动端与管理后台页面设计

### 5.1 uni-app 移动端

- 家长端：课程套餐、在线报名、缴费记录、学员课表、学情详情、课时余额、消息通知；
- 教师端：我的课表、课堂考勤、作业发布、学情点评、调课申请、课时统计。

### 5.2 Vue3 管理后台

- 教务端：课程管理、班级管理、智能排课、调课管理、学员档案、报名审核、考级管理；
- 财务端：收费台账、续费管理、退费审核、课时消耗报表、教师薪资结算页、营收统计；
- 管理端：用户管理、角色权限、机构配置、公告管理、全局数据看板、操作日志。

## 6. 运行与部署建议

| 模块 | 技术 | 部署/运行方式 |
|---|---|---|
| 移动端 | uni-app | H5 运行、微信小程序演示或 App 打包 |
| 管理后台 | Vue3 + Element Plus | Nginx 托管静态资源 |
| 后端 | Spring Boot | Jar 包运行 |
| 数据库 | MySQL 8.0 | 本地或云服务器 |
| 缓存 | Redis | 本地或云服务器 |

## 7. 毕业论文建议表达

论文中可将“为什么家长端和教师端采用 uni-app，而管理端采用 Vue3 后台”作为一个设计亮点来写：

1. 家长与教师以移动端高频轻量操作为主；
2. 教务、财务和管理员以 PC 端复杂管理操作为主；
3. 两端共用统一后端接口，既减少重复开发，又保持业务规则一致。
