请绘制一张 UML 系统用例图（Use Case Diagram），注意是「用例图」不是「流程图」。

【图形标题】艺术培训机构教务管理平台——系统用例图

【系统边界】画一个矩形框，标题写在框顶：「艺术培训机构教务管理平台」。所有用例（椭圆）都放在这个框内部；所有参与者（小人图形）都放在框外部。

【参与者】共 6 个，全部画成经典火柴人小人：
1. 用户
2. 学员家长
3. 授课教师
4. 教务管理员
5. 财务管理员
6. 超级管理员

【用例】共 26 个，全部画成椭圆形，放在系统边界框内：
- 公共：登录与身份认证
- 学员家长的用例：在线报名、缴费与续费、查看课表与学情、查询课时余额
- 授课教师的用例：查看授课课表、课堂考勤、课时自动扣减、请假审批、作业发布与学情点评
- 教务管理员的用例：课程班级管理、智能排课、排课冲突检测、调课审批、学员管理与报名审核、转班退班、考级管理
- 财务管理员的用例：收费与续费登记、退费审核、退费课时回冲、教师薪资结算、营收与课时统计、报表导出
- 超级管理员的用例：用户与角色权限管理、机构配置与公告管理、全局运营看板

【关系】
1. 关联（实线，无箭头）：参与者与自己的用例相连
   - 用户 → 登录与身份认证
   - 学员家长 → 在线报名、查看课表与学情、查询课时余额
   - 授课教师 → 查看授课课表、课堂考勤、请假审批、作业发布与学情点评
   - 教务管理员 → 课程班级管理、智能排课、调课审批、学员管理与报名审核、考级管理
   - 财务管理员 → 收费与续费登记、退费审核、教师薪资结算、营收与课时统计
   - 超级管理员 → 用户与角色权限管理、机构配置与公告管理、全局运营看板
2. 包含（虚线箭头，线上标注 «include»）
   - 在线报名 «include» 缴费与续费
   - 课堂考勤 «include» 课时自动扣减
   - 智能排课 «include» 排课冲突检测
   - 退费审核 «include» 退费课时回冲
3. 扩展（虚线箭头，线上标注 «extend»）
   - 学员管理与报名审核 «extend» 转班退班
   - 营收与课时统计 «extend» 报表导出
4. 泛化（实线箭头，箭头处为空心三角形）
   - 学员家长 → 用户
   - 授课教师 → 用户
   - 教务管理员 → 用户
   - 财务管理员 → 用户
   - 超级管理员 → 用户

【布局与样式】
- 参与者统一排在图的左侧，用例按角色分组自左向右依次排布，同一角色的用例纵向对齐成一列，避免连线交叉。
- 黑白学术风格：白色背景、深灰色线条、黑色文字，不要使用彩色、不要渐变、不要阴影、不要装饰性图标。
- 线条简洁笔直，标签文字不要显示成乱码。
