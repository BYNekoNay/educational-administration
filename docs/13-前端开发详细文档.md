# 移动端与管理后台开发详细文档

> **版本状态**：v0.8 规划版。本文档细化 uni-app 移动端与 Vue3 管理后台的页面、组件和交互实现。

## 1. 终端总体设计

系统终端层分为两个独立工程：

1. **mobile-uniapp**：服务学员家长和授课教师，适合 H5、微信小程序或 App 场景；
2. **admin-web**：服务教务管理员、财务管理员和超级管理员，适合 PC 管理后台场景。

两个工程共享同一套 Spring Boot REST API，但界面形态、操作密度和交互方式不同。

## 2. uni-app 移动端（家长端 + 教师端）

### 2.1 技术栈

uni-app、Vue3 语法、Pinia、uView 或 uni-ui、Axios/uni.request 封装。

### 2.2 工程结构

```
mobile-uniapp/
├── pages/
│   ├── login/
│   ├── parent/
│   │   ├── courses/
│   │   ├── enrollments/
│   │   ├── payments/
│   │   ├── schedule/
│   │   ├── learning/
│   │   ├── lesson-account/
│   │   └── notices/
│   └── teacher/
│       ├── schedule/
│       ├── adjust-requests/
│       ├── attendance/
│       ├── homework/
│       ├── learning-records/
│       └── statistics/
├── components/
├── api/
├── store/
├── utils/
```

### 2.3 家长端页面

| 页面 | 路径 | 功能 |
|---|---|---|
| 课程套餐 | `/pages/parent/courses/index` | 查看课程、提交报名 |
| 报名记录 | `/pages/parent/enrollments/index` | 查看审核状态 |
| 缴费记录 | `/pages/parent/payments/index` | 查看缴费、续费、退费记录 |
| 学员课表 | `/pages/parent/schedule/index` | 周课表、课程详情 |
| 学情记录 | `/pages/parent/learning/index` | 考勤、作业、教师评语 |
| 课时余额 | `/pages/parent/lesson-account/index` | 剩余课时、课时流水 |
| 消息通知 | `/pages/parent/notices/index` | 上课提醒、调课、公告 |

重点交互：

- 课表页面采用卡片式周视图，方便手机查看；
- 课时余额低于阈值时展示续费提示；
- 通知列表支持未读标记和详情跳转。

### 2.4 教师端页面

| 页面 | 路径 | 功能 |
|---|---|---|
| 我的课表 | `/pages/teacher/schedule/index` | 查看授课安排 |
| 调课申请 | `/pages/teacher/adjust-requests/index` | 提交和查看调课申请 |
| 课堂考勤 | `/pages/teacher/attendance/index` | 设置到课、请假、缺勤、迟到 |
| 作业发布 | `/pages/teacher/homework/index` | 发布课次作业 |
| 学情点评 | `/pages/teacher/learning-records/index` | 填写学员表现和评语 |
| 课时统计 | `/pages/teacher/statistics/index` | 月度课时和完成率 |

重点交互：

- 考勤页支持“全部到课”一键填充，再单独修改异常学员；
- 作业和评语页以单课次为单位，避免教师在移动端处理过多复杂表格；
- 教师端首页可直接展示“今日待上课课次”。

### 2.5 移动端公共组件

| 组件 | 用途 |
|---|---|
| MobileCourseCard | 课程/课次卡片 |
| MobileScheduleList | 手机端课表列表 |
| AttendanceQuickPanel | 一键考勤快捷面板 |
| NoticeList | 通知列表 |
| LessonBalanceCard | 课时余额卡片 |
| UploadAttachment | 作业附件上传 |

### 2.6 移动端请求封装

- `uni.request` 或封装 Axios 统一携带 Token；
- 401 跳转登录页；
- 403 显示无权限提示；
- 请求错误统一弹出轻提示，避免复杂错误页打断课堂操作。

## 4. 图表设计

图表主要集中在管理后台。

| 图表 | 类型 | 数据来源 |
|---|---|---|
| 招生趋势 | 折线图 | `/api/admin/statistics/enrollments` |
| 到课率 | 折线图/仪表盘 | `/api/admin/statistics/attendance-rate` |
| 课时消耗 | 折线图 | `/api/admin/statistics/lesson-consumption` |
| 课程营收 | 柱状图 | `/api/finance/statistics/revenue` |
| 教师工作量 | 柱状图 | `/api/admin/statistics/teacher-workload` |
| 学员流失率 | 折线图 | `/api/admin/statistics/student-loss` |

## 5. 表单校验与交互规则

- 手机号、金额、课时、日期时间等字段客户端先做格式校验；
- 排课结束时间必须晚于开始时间；
- 课程价格、课时数、教室容量必须为正数；
- 薪资调整金额需填写原因；
- 移动端优先减少输入项，后台优先增强批量操作和筛选能力。

## 6. 测试建议

- uni-app：重点验证登录、课表、考勤、作业、学情、通知在 H5 和微信开发者工具中的表现；
- Vue3 后台：重点验证排课、收费、薪资、统计、导出和权限管理；
- 可对纯函数如时间冲突判断、图表数据转换、表单校验规则编写单元测试。
