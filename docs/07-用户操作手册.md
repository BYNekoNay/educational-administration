# 用户操作手册

> **版本状态**：v1.3.0 正式版，已与实际代码和测试结果核对，同步日期 2026-10-04。

## 1. 手册目的

本文档说明“艺术培训机构全流程教务管理平台”的运行环境、登录方式和五类角色的主要操作流程，作为毕业设计成果中的软件使用说明书。

## 2. 运行环境

### 2.1 硬件环境

| 项目 | 建议配置 |
|---|---|
| 客户端 | 普通 PC 浏览器、移动设备浏览器（H5） |
| 服务端 | 2 核 CPU、4GB 内存及以上 |
| 存储 | 20GB 以上可用磁盘空间 |

### 2.2 软件环境

| 项目 | 建议版本 |
|---|---|
| 操作系统 | Windows 10/11、Ubuntu、CentOS |
| 浏览器/调试工具 | Chrome、Edge 等现代浏览器 |
| JDK | JDK 17 或项目最终指定版本 |
| Node.js | Node.js 18 LTS 或项目最终指定版本 |
| 数据库 | MySQL 8.0 |
| 缓存 | Redis 7（可选；未部署时缓存与登录计数自动降级为应用内存） |
| Web 服务器 | Nginx，可选 |

## 3. 登录与公共操作

### 3.1 登录系统

1. 打开系统访问地址；
2. 输入用户名和密码；
3. 点击登录；
4. 系统根据账号角色进入对应首页。

**如果登录后直接跳到「修改密码」页** —— 说明你的密码是管理员代设或重置的，不是你本人设的。这是有意的安全设计：改密之前其他功能一律不可用，点任何菜单都会回到这里。

1. 输入原密码（管理员交给你的那个）与新密码（至少 6 位，不能与原密码相同）；
2. 确认后系统会要求用新密码重新登录；
3. 其他设备上的登录同时失效。

**如果提示「用户名或密码错误；如密码刚被管理员重置，请向教务索取新密码」** —— 说明密码已失效。请联系管理员或教务重置；他们看不到你的新密码，但可以为你重置一个临时密码，你登录后再改成自己的。

### 3.2 退出登录

点击右上角用户信息区域，选择退出登录，系统清除本地登录状态并返回登录页。

### 3.3 常见提示

- “无权限访问”：当前账号角色不能使用该功能；
- “登录已过期”：Token 失效，需要重新登录；
- “数据不存在”：记录已删除或当前账号无权查看；
- “操作成功/失败”：根据弹窗提示确认后续操作。

## 4. 学员家长端操作

学员家长通过 uni-app 移动端使用本模块，本次交付形态为 H5。微信小程序与 App 端为规划中能力，未纳入本次交付验证。

### 4.1 在线报名

1. 进入"课程套餐"；
2. 按课程分类或关键词查找课程；
3. 点击报名，填写学员姓名、年龄、联系电话等信息；
4. 提交报名申请；
5. 等待教务审核；审核通过后请在系统提示的留位时限内完成缴费，超时名额将自动释放。

### 4.2 查看缴费记录

1. 进入“缴费记录”；
2. 选择学员或时间范围；
3. 查看学费、续费、退费等记录。

### 4.3 查看课表

1. 进入“我的课表”；
2. 选择学员和日期范围；
3. 查看上课日期、时间、课程、教师和教室。

### 4.4 查看学情与作业

1. 进入“学情记录”；
2. 选择具体课次；
3. 查看考勤状态、课堂作业、教师评语和成长记录。

### 4.5 查询剩余课时

1. 进入“课时余额”；
2. 查看每门课程的累计购买课时、已消耗课时、剩余课时和到期日期；
3. 点击明细可查看课时流水。

### 4.6 查看通知

进入“消息通知”，可查看上课提醒、调课通知、考级通知和机构公告。

### 4.7 绑定学员

新注册家长首次登录时若还没有孩子，首页会显示“还没有绑定孩子”提示卡。

1. 点击该提示卡，或进入「常用功能 > 绑定学员」；
2. 填写学员真实姓名、报名时登记的联系电话、与学员的关系；
3. 点击「确认绑定」；
4. 姓名与电话同时匹配到一名学员时绑定成功，首页出现孩子，随后可查看课时、课表与学情；
5. 若提示“未找到匹配的学员”，请核对信息后重试或联系机构教务；若提示“匹配到多名学员”，需由教务在管理后台人工绑定。

> 同一账号可绑定多个孩子；绑定后在首页「我的孩子」区域切换当前查看的孩子。为避免信息被枚举，同一账号短时间内连续提交超过 10 次会被临时限制。

## 5. 授课教师端操作

授课教师通过 uni-app 移动端使用本模块，便于在课堂现场完成查看课表、考勤、作业和学情点评。

### 5.1 查看个人课表

教师登录后进入“我的课表”，按日历或列表查看授课安排。

### 5.2 提交调课申请

1. 在课表中选择需要调整的课次；
2. 点击调课申请；
3. 填写调课原因和期望时间；
4. 提交后等待教务审核，可在"我的调课申请"中查看审核状态（待审核/已通过/已驳回）。

### 5.3 课堂考勤

1. 进入“课堂考勤”；
2. 选择待上课课次；
3. 对学员设置到课、请假、缺勤或迟到；
4. 提交考勤；
5. 系统根据规则自动扣减课时。

### 5.4 发布作业与点评

1. 进入课次详情；
2. 填写课堂作业内容，可上传附件；
3. 对每位学员填写课堂表现和教师评语；
4. 保存后家长端可查看。

### 5.5 查看课时统计

进入“课时统计”，选择月份后查看主讲课时、代课课时和课程完成率。

### 5.6 审批学员请假

1. 进入“请假审批”，查看本班学员提交的待审批请假申请；
2. 选择通过或驳回；通过后该学员当次考勤记为“请假”并**不扣课时**（已批准请假不可再被覆盖为到课/迟到）。

### 5.7 查看我的课酬

1. 移动端首页点击「我的课酬」（票据图标）；
2. 页面顶部为两个统计卡：**本年合计**（金额）与**结算月份**（有记录的月数）；
3. 中部是月度列表，每行显示月份、主讲/代课节数、金额与结算状态（待确认 / 已确认 / 已发放 / 已撤销）；
4. 点击任一月度行，底部弹出明细：授课节数、代课节数、基础课酬、代课课酬、奖金、合计；
5. 课酬由财务结算后生成，教师**只能看到本人数据**；如有疑问请联系财务。

> 与 5.5「课时统计」的区别：课时统计看的是**课次维度**（上了多少节），我的课酬看的是**金额维度**（能拿多少钱），两者不是一回事。

## 6. 教务管理员端操作

### 6.1 课程与班级管理

1. 进入“课程管理”，新增课程类型、课时、时长和收费标准；
2. 进入“班级管理”，选择课程、教师、容量和开班日期创建班级；
3. 将审核通过的学员加入班级。

### 6.2 报名审核

1. 进入“报名审核”；
2. 查看家长提交的报名信息；
3. 审核通过后选择课程和班级；
4. 审核拒绝时填写拒绝原因。

### 6.3 智能排课

1. 进入“智能排课”；
2. 选择班级、教师、教室、日期范围、上课周期和时间段；
3. 点击冲突检测；
4. 无冲突时确认生成课次；
5. 有冲突时根据提示调整教师、教室或时间。

### 6.4 调课管理

1. 进入"调课管理"；
2. 查看教师发起的调课申请（待审核状态），或直接发起教务手动调课；
3. 审核教师申请：通过则系统按新时间/教师/教室生成新课次并关闭原课次，驳回则申请状态变为已驳回、原课次不变；
4. 保存后系统更新课表并生成通知。

### 6.5 学员档案与转班退班

1. 进入“学员档案”；
2. 可新增、编辑、查询学员信息；
3. 选择学员后可发起转班或退班；
4. 退费相关流程需转交财务审核。

### 6.6 考级管理

1. 创建考级项目；
2. 添加报名学员；
3. 录入考级成绩；
4. 上传或登记证书编号。

### 6.7 教师管理

> 改造前教师只能由超级管理员维护，教务登录后侧栏看不到任何教师入口。现在教务可直接管理。

**进入**：侧栏「教务管理 > 教师管理」。

**教师列表**：显示姓名、账号、手机、入职日、状态、可授课程。状态有三态：

| 显示 | 含义 | 该怎么做 |
|---|---|---|
| 在职 | 正常在岗 | — |
| 将于 YYYY-MM-DD 离职 | 已登记未来离职日，仍在岗 | 安排接替者 |
| 已过离职日未停用（红色） | 离职日已过但账号仍启用 | 补办离职，或改回在职 |

列表中的「待改密」标记表示该教师密码是管理员代设或重置的，其首次登录会被强制改密。

**查看详情**：点行内「详情」，弹出三个标签页——**档案**（账号/手机/入职日/状态/可授课程）、**当前任教**（正在带的班级，可在此直接换师）、**历史任教**（由已完成课次回溯，用于查证"这个班以前是谁带的"）。

**换任课教师**：选班级 → 选新教师 → 确认。系统**只改未完成且未来的课次**，已上过的课与历史薪资不受影响，完成后提示改派了几条。

**办理离职**：

1. 点行内「离职」；
2. 填写离职生效日（可填未来日期，表示"带完这个月"）；
3. 确认后一次完成三件事：写入离职日、**停用账号**、递增 Token 版本（该教师所有已登录设备立即下线）。

> 离职**不会**自动清理该教师名下的未来课次——这是有意的。交接需要人工确认接替者，避免系统擅自把课派给不合适的人。请在办理离职前先用「换师」安排好。

## 7. 财务管理员端操作

### 7.1 收费与续费

1. 进入“收费管理”；
2. 选择学员和课程套餐；
3. 填写金额和支付方式；
4. 保存后系统生成收费记录并增加课时。

### 7.2 退费审核

1. 进入"退费审核"；
2. 查看退费申请、剩余课时和建议退费金额（系统自动校验不超过该学员已缴费金额上限，超出部分需人工核实）；
3. 若申请人为财务本人，系统将自动转交其他财务人员复核；
4. 审核通过后系统生成退费记录并调整课时账户；
5. 审核拒绝时填写原因。

### 7.3 课时消耗报表

进入“课时消耗”，按学员、班级、课程或时间范围查看消耗明细，并可导出报表。

### 7.4 教师薪资结算

1. 进入"薪资结算"；
2. 选择教师和月份；
3. 点击生成结算单；
4. 核对主讲课时、代课课时、课时单价和应发金额；
5. 确认后结算单锁定；如后续发现对应课次或考勤有变动，通过"薪资调整"功能追加调整记录，不会覆盖已确认的原结算单。

### 7.5 营收统计

进入“营收统计”，查看月度/年度营收、课程盈利分析和收费率统计图表。

### 7.6 课时人工调整

用于补课、赠送课时、误扣回补等非缴费场景，由财务或超级管理员操作。

1. 进入“课时账户”，在目标学员所在行点击「调整课时」；
2. 选择方向（增加课时 / 扣减课时），填写课时数与调整原因（必填）；
3. 弹窗实时显示“调整后剩余”，确认无误后点击「确定调整」；
4. 调整成功后剩余课时与总课时同步变化，课时流水新增一条来源类型为“人工调整”的记录。

> 注意：扣减超过当前剩余课时会被直接拒绝（不会自动扣到 0），请核对后重试；每条调整都会写入操作日志，可按课时账户追溯操作人与原因。

## 8. 超级管理员端操作

### 8.1 人员权限管理

1. 进入“用户管理”；
2. 新增或编辑用户（**新建时密码由系统随机生成，只在创建瞬间显示一次，请当场复制交给本人**）；
3. 分配角色；
4. 禁用或启用账号。

**重置密码**：点行内「重置密码」，系统生成临时密码并打上「待改密」标记。该用户**所有已登录设备立即下线**，下次登录被强制跳转到改密页。重置后请把临时密码告知本人——管理员看不到他后续改成的新密码。

**教师账号的日常维护**（建档、换任课教师、办理离职）已下放至教务端「教务管理 > 教师管理」，超管仍保留全量入口，详见 §6.7。

**操作审计**：重置密码、办理离职、换师、教师查看家长联系方式均写入 `operation_log`，可按操作对象反查「谁动过这个账号/学员」。

### 8.2 机构配置

维护机构名称、联系方式、校区、教室和系统参数。

### 8.3 公告管理

1. 进入“公告管理”；
2. 新增公告，填写标题、内容和接收范围；
3. 发布后对应用户可在通知中查看。

### 8.4 全局运营看板

查看招生数据、学员流失率、营收数据、课时消耗趋势和教师工作量总览。

### 8.5 操作日志

按操作人、模块和时间范围查询敏感操作记录。

## 9. 常见问题

| 问题 | 处理方式 |
|---|---|
| 无法登录 | 检查账号密码是否正确，账号是否被禁用 |
| 看不到某个菜单 | 当前角色没有该菜单权限 |
| 排课提示冲突 | 根据冲突明细调整教师、教室或时间 |
| 课时不足 | 联系财务续费或由教务核对课时账户 |
| 薪资金额异常 | 检查课次是否已完成、薪资规则是否正确 |
| 统计图表为空 | 检查是否已有报名、考勤、收费等测试数据 |
