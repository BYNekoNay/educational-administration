# 用户操作手册

> **版本状态**：v0.9 规划版，基于毕业设计需求编制。最终版本应根据实际界面、菜单名称和演示账号补充截图。

## 1. 手册目的

本文档说明“艺术培训机构全流程教务管理平台”的运行环境、登录方式和五类角色的主要操作流程，作为毕业设计成果中的软件使用说明书。

## 2. 运行环境

### 2.1 硬件环境

| 项目 | 建议配置 |
|---|---|
| 客户端 | 普通 PC 浏览器、移动设备、微信开发者工具或 H5 浏览器 |
| 服务端 | 2 核 CPU、4GB 内存及以上 |
| 存储 | 20GB 以上可用磁盘空间 |

### 2.2 软件环境

| 项目 | 建议版本 |
|---|---|
| 操作系统 | Windows 10/11、Ubuntu、CentOS |
| 浏览器/调试工具 | Chrome、Edge、微信开发者工具、HBuilderX |
| JDK | JDK 17 或项目最终指定版本 |
| Node.js | Node.js 18 LTS 或项目最终指定版本 |
| 数据库 | MySQL 8.0 |
| 缓存 | Redis 6.x 及以上 |
| Web 服务器 | Nginx，可选 |

## 3. 登录与公共操作

### 3.1 登录系统

1. 打开系统访问地址；
2. 输入用户名和密码；
3. 点击登录；
4. 系统根据账号角色进入对应首页。

### 3.2 退出登录

点击右上角用户信息区域，选择退出登录，系统清除本地登录状态并返回登录页。

### 3.3 常见提示

- “无权限访问”：当前账号角色不能使用该功能；
- “登录已过期”：Token 失效，需要重新登录；
- “数据不存在”：记录已删除或当前账号无权查看；
- “操作成功/失败”：根据弹窗提示确认后续操作。

## 4. 学员家长端操作

学员家长通过 uni-app 移动端使用本模块，可运行在 H5、微信小程序或 App 形态。

### 4.1 在线报名

1. 进入"课程套餐"；
2. 按课程分类或关键词查找课程；
3. 点击报名，填写学员姓名、年龄、联系电话等信息；
4. 提交报名申请；
5. 等待教务审核；审核通过后请在系统提示的留位时限内完成缴费，超时名额将自动释放。

### 4.2 查看缴费记录

1. 进入“缴费记录”；
2. 选择学员或时间范围；
3. 查看学费、续费、退费等记录。

### 4.3 查看课表

1. 进入“我的课表”；
2. 选择学员和日期范围；
3. 查看上课日期、时间、课程、教师和教室。

### 4.4 查看学情与作业

1. 进入“学情记录”；
2. 选择具体课次；
3. 查看考勤状态、课堂作业、教师评语和成长记录。

### 4.5 查询剩余课时

1. 进入“课时余额”；
2. 查看每门课程的累计购买课时、已消耗课时、剩余课时和到期日期；
3. 点击明细可查看课时流水。

### 4.6 查看通知

进入“消息通知”，可查看上课提醒、调课通知、考级通知和机构公告。

## 5. 授课教师端操作

授课教师通过 uni-app 移动端使用本模块，便于在课堂现场完成查看课表、考勤、作业和学情点评。

### 5.1 查看个人课表

教师登录后进入“我的课表”，按日历或列表查看授课安排。

### 5.2 提交调课申请

1. 在课表中选择需要调整的课次；
2. 点击调课申请；
3. 填写调课原因和期望时间；
4. 提交后等待教务审核，可在"我的调课申请"中查看审核状态（待审核/已通过/已驳回）。

### 5.3 课堂考勤

1. 进入“课堂考勤”；
2. 选择待上课课次；
3. 对学员设置到课、请假、缺勤或迟到；
4. 提交考勤；
5. 系统根据规则自动扣减课时。

### 5.4 发布作业与点评

1. 进入课次详情；
2. 填写课堂作业内容，可上传附件；
3. 对每位学员填写课堂表现和教师评语；
4. 保存后家长端可查看。

### 5.5 查看课时统计

进入“课时统计”，选择月份后查看主讲课时、代课课时和课程完成率。

## 6. 教务管理员端操作

### 6.1 课程与班级管理

1. 进入“课程管理”，新增课程类型、课时、时长和收费标准；
2. 进入“班级管理”，选择课程、教师、容量和开班日期创建班级；
3. 将审核通过的学员加入班级。

### 6.2 报名审核

1. 进入“报名审核”；
2. 查看家长提交的报名信息；
3. 审核通过后选择课程和班级；
4. 审核拒绝时填写拒绝原因。

### 6.3 智能排课

1. 进入“智能排课”；
2. 选择班级、教师、教室、日期范围、上课周期和时间段；
3. 点击冲突检测；
4. 无冲突时确认生成课次；
5. 有冲突时根据提示调整教师、教室或时间。

### 6.4 调课管理

1. 进入"调课管理"；
2. 查看教师发起的调课申请（待审核状态），或直接发起教务手动调课；
3. 审核教师申请：通过则系统按新时间/教师/教室生成新课次并关闭原课次，驳回则申请状态变为已驳回、原课次不变；
4. 保存后系统更新课表并生成通知。

### 6.5 学员档案与转班退班

1. 进入“学员档案”；
2. 可新增、编辑、查询学员信息；
3. 选择学员后可发起转班或退班；
4. 退费相关流程需转交财务审核。

### 6.6 考级管理

1. 创建考级项目；
2. 添加报名学员；
3. 录入考级成绩；
4. 上传或登记证书编号。

## 7. 财务管理员端操作

### 7.1 收费与续费

1. 进入“收费管理”；
2. 选择学员和课程套餐；
3. 填写金额和支付方式；
4. 保存后系统生成收费记录并增加课时。

### 7.2 退费审核

1. 进入"退费审核"；
2. 查看退费申请、剩余课时和建议退费金额（系统自动校验不超过该学员已缴费金额上限，超出部分需人工核实）；
3. 若申请人为财务本人，系统将自动转交其他财务人员复核；
4. 审核通过后系统生成退费记录并调整课时账户；
5. 审核拒绝时填写原因。

### 7.3 课时消耗报表

进入“课时消耗”，按学员、班级、课程或时间范围查看消耗明细，并可导出报表。

### 7.4 教师薪资结算

1. 进入"薪资结算"；
2. 选择教师和月份；
3. 点击生成结算单；
4. 核对主讲课时、代课课时、课时单价和应发金额；
5. 确认后结算单锁定；如后续发现对应课次或考勤有变动，通过"薪资调整"功能追加调整记录，不会覆盖已确认的原结算单。

### 7.5 营收统计

进入“营收统计”，查看月度/年度营收、课程盈利分析和收费率统计图表。

## 8. 超级管理员端操作

### 8.1 人员权限管理

1. 进入“用户管理”；
2. 新增或编辑用户；
3. 分配角色；
4. 禁用或启用账号。

### 8.2 机构配置

维护机构名称、联系方式、校区、教室和系统参数。

### 8.3 公告管理

1. 进入“公告管理”；
2. 新增公告，填写标题、内容和接收范围；
3. 发布后对应用户可在通知中查看。

### 8.4 全局运营看板

查看招生数据、学员流失率、营收数据、课时消耗趋势和教师工作量总览。

### 8.5 操作日志

按操作人、模块和时间范围查询敏感操作记录。

## 9. 常见问题

| 问题 | 处理方式 |
|---|---|
| 无法登录 | 检查账号密码是否正确，账号是否被禁用 |
| 看不到某个菜单 | 当前角色没有该菜单权限 |
| 排课提示冲突 | 根据冲突明细调整教师、教室或时间 |
| 课时不足 | 联系财务续费或由教务核对课时账户 |
| 薪资金额异常 | 检查课次是否已完成、薪资规则是否正确 |
| 统计图表为空 | 检查是否已有报名、考勤、收费等测试数据 |
